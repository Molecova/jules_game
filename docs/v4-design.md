# 카드 원정대 v4 시스템 설계 — 3클래스 · 전직 · 상점/창고/합성

v3(6계열, 보상으로 카드 획득, 유닛 경험치)를 오토체스형 경제로 바꾸는 설계안입니다.
전투 엔진, 격자 스킬 패턴, 상태이상, 딱지·칩 아트, 지도는 그대로 씁니다.

---

## 1. 핵심 구조 한눈에

```
지도에서 노드 선택 → [준비 단계] 수입 → 상점(유닛5·스킬5·아이템5) → 구매/판매/리롤
                              → 창고(8칸) ↔ 보드 배치 / 딱지에 칩·아이템 장착 → 같은 카드 3장 자동 합성
                   → [전투] 자동 → 승: 골드 / 패: 원정대 체력 감소 → 다음 노드
```

- **클래스는 3개**: 전사 · 궁수 · 마법사. 유닛 카드는 이 셋 중 하나의 "베이스 캐릭터"입니다.
- **성향 3색**: 스킬 칩과 아이템에는 색이 있습니다. 🔴투지 · 🟡신성 · 🟣책략 (+ 무색).
- **전직**: 한 딱지의 3칸(스킬 2 + 아이템 1) 중 같은 색이 **2개 이상이면 전직**, **3개면 마스터**.
  - 전사 + 🟡신성 = 성기사, 전사 + 🟣책략 = 도적 …처럼 "클래스 × 색" 9칸 표로 정해집니다.
- **상점**: 매 라운드 유닛 5장 · 스킬 5장 · 아이템 5장이 진열됩니다.
- **창고 8칸**: 유닛·스킬·아이템 카드 아무거나 보관합니다. 딱지에 장착된 칩은 창고 칸을 차지하지 않습니다.
- **합성**: 같은 카드(같은 별) 3장 → ★2, ★2 3장 → ★3. 유닛·스킬·아이템 모두 해당.

## 2. 클래스 (베이스)

| 클래스 | 기본 역할 | 기본 스탯 성격 | 쓸 수 있는 스킬 |
| --- | --- | --- | --- |
| 전사 | 근접 · 앞줄 | 체력 높음, 사거리 1 | 전사 스킬 |
| 궁수 | 원거리 물리 | 공속 빠름, 사거리 3 | 궁수 스킬 |
| 마법사 | 원거리 스킬 | 마나 빠름, 사거리 3, 체력 낮음 | 마법사 스킬 |

- 스킬은 **클래스 전용**(전사 스킬은 전사만), 아이템은 **누구나** 장착.
- 무색 공용 스킬은 누구나 장착하지만 전직 색으로 세지 않습니다.

## 3. 전직표 (클래스 × 성향)

같은 색 2개 = 전직, 3개 = 마스터. 색이 1·1·1로 갈리면 전직 없음(베이스 그대로).
전직하면 딱지 테두리에 해당 색 리본과 전직 문장 스티커가 붙습니다.

| | 🔴 투지 | 🟡 신성 | 🟣 책략 |
| --- | --- | --- | --- |
| **전사** | **광전사** — 체력 50% 이하에서 공속 +40%, 흡혈 15%<br>마스터: 처음 쓰러질 때 2초간 버팀 | **성기사** — 받는 피해 −15%, 스킬 사용 시 주변 아군 회복<br>마스터: 주변 1칸 아군도 받는 피해 −10% | **도적** — 전투 시작 시 적 후열로 도약, 치명 +20%<br>마스터: 첫 공격 확정 치명, 처치 시 1.5초 은신 |
| **궁수** | **사냥꾼** — 같은 대상 연속 공격마다 피해 +8%(최대 +40%)<br>마스터: 사냥매 소환 | **성궁사** — 공격 3회마다 가장 다친 아군에게 치유 화살<br>마스터: 치유 화살이 보호막도 줌 | **지원가** — 맞힌 적에 표식(받는 피해 +12%), 주변 아군 공속 +15%<br>마스터: 표식 +25% |
| **마법사** | **원소술사**(공격) — 스킬 위력 +25%, 스킬에 화상·둔화 추가<br>마스터: 2회 시전마다 메아리 1회 | **사제**(힐) — 치유·보호막 +40%, 아군 쓰러지면 마나 +30<br>마스터: 전투당 1회 아군 부활(30%) | **마도사**(지원) — 시작 마나 +40, 스킬 사용 시 주변 아군 마나 +15<br>마스터: 스킬 적중 적 1초 기절 |

요청하신 전사→성기사/도적, 궁수→사냥꾼/지원가, 마법사→공격/힐/지원이 모두 들어가고,
표를 채우기 위해 광전사와 성궁사를 추가했습니다.

## 7. 창고 8칸 · 장착

- 창고는 8칸, 카드 1장 = 1칸(종류 무관).
- 유닛 딱지는 장착한 칩·아이템을 **올린 채로** 창고에 들어갑니다(칸은 1개만 씀).
- 장착: 창고의 칩을 딱지 슬롯으로 드래그. 이미 찬 슬롯에 놓으면 **맞교환**.
- 해제: 슬롯에서 창고로 드래그(창고에 빈칸 필요).
- 창고가 꽉 차면 구매 불가. **단, 그 구매로 합성이 되면 구매 가능**(오토체스 규칙).
- 출전 유닛 수 = 원정대 레벨. 보드에 있는 유닛은 창고 칸을 쓰지 않습니다.

## 8. 합성 규칙

- 같은 카드 · 같은 별 3장이 모이는 순간 자동 합성(준비 단계에서만).
- 세는 범위: **보드 + 창고 + 딱지에 장착된 칩/아이템**.
- 결과물 위치: 보드에 있는 쪽 > 장착된 쪽 > 창고 순으로 그 자리를 이어받음.
- 유닛 합성 시 장비: 남는 딱지의 장비는 유지, 나머지 두 딱지의 장비는 창고로 돌아감.
  창고가 모자라면 넘치는 카드는 **정가로 자동 판매**하고 알림 표시.
  돌아온 칩으로 다시 3장이 되면 연쇄 합성.
- 스탯: 유닛 ★2 = 체력·공격 ×1.8, ★3 = ×3.2.
- 연출: 딱지 3장이 겹쳐 눌리고 도장 "★2"가 찍힘. ★2 딱지는 두께 2배 + 은박 테, ★3은 금박 테.
- 판매가: ★1 = 가격 그대로, ★2 = 가격×3 −1, ★3 = 가격×9 −2.

## 11. 유물 (v3 30종 → 20종 정리)
