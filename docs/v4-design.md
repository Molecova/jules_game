# 카드 원정대 v4 시스템 설계 — 3클래스 · 클래스 전용 아이템 · 상점/창고/합성

v3(6계열, 보상으로 카드 획득, 유닛 경험치)를 오토체스형 경제로 바꾸는 설계안입니다.
전투 엔진, 격자 스킬 패턴, 상태이상, 딱지·칩 아트, 지도는 그대로 씁니다.

---

## 1. 핵심 구조 한눈에

```
지도에서 노드 선택 → [준비 단계] 수입 → 상점(유닛5·스킬5·아이템5) → 구매/판매/리롤
                              → 창고(8칸) ↔ 보드 배치 / 딱지에 칩·아이템 장착 → 같은 카드 3장 자동 합성
                   → [전투] 자동 → 승: 골드·다음 노드 / 패: 원정 종료(게임 오버)
```

- **클래스는 3개**: 전사 · 궁수 · 마법사. 유닛 카드는 이 셋 중 하나의 "베이스 캐릭터"입니다.
- **스킬과 아이템도 클래스 전용**: 전사 스킬/아이템은 전사만, 궁수 것은 궁수만, 마법사 것은 마법사만 장착.
- **성향·색·전직 구분은 없음**. 대신 아이템마다 기본 공격이나 역할을 바꾸는 효과가 있어서,
  같은 전사라도 어떤 아이템을 끼느냐에 따라 탱커·암살자·광전사처럼 다르게 느껴집니다.
- **상점**: 매 라운드 유닛 5장 · 스킬 5장 · 아이템 5장이 진열됩니다.
- **창고 8칸**: 유닛·스킬·아이템 카드 아무거나 보관합니다. 딱지에 장착된 칩은 창고 칸을 차지하지 않습니다.
- **합성**: 같은 카드(같은 별) 3장 → ★2, ★2 3장 → ★3. 유닛·스킬·아이템 모두 해당.

## 7. 창고 8칸 · 장착

- 창고는 8칸, 카드 1장 = 1칸(종류 무관).
- 유닛 딱지는 장착한 칩·아이템을 **올린 채로** 창고에 들어갑니다(칸은 1개만 씀).
- 장착: 창고의 칩을 딱지 슬롯으로 드래그(같은 클래스만). 이미 찬 슬롯에 놓으면 **맞교환**.
- 해제: 슬롯에서 창고로 드래그(창고에 빈칸 필요).
- 창고가 꽉 차면 구매 불가. **단, 그 구매로 합성이 되면 구매 가능**(오토체스 규칙).
- 출전 유닛 수 = 원정대 레벨. 보드에 있는 유닛은 창고 칸을 쓰지 않습니다.

## 8. 합성 규칙

- 같은 카드 · 같은 별 3장이 모이는 순간 자동 합성(준비 단계에서만).
- 세는 범위: **보드 + 창고 + 딱지에 장착된 칩/아이템**.
- 결과물 위치: 보드에 있는 쪽 > 장착된 쪽 > 창고 순으로 그 자리를 이어받음.
- 유닛 합성 시 장비: 남는 딱지의 장비는 유지, 나머지 두 딱지의 장비는 창고로 돌아감.
  창고가 모자라면 넘치는 카드는 **정가로 자동 판매**하고 알림 표시.
  돌아온 칩으로 다시 3장이 되면 연쇄 합성.
- 스탯: 유닛 ★2 = 체력·공격 ×2, ★3 = ×4 (스킬 위력은 ×1.7, ×2.8).
- 연출: 딱지 3장이 겹쳐 눌리고 도장 "★2"가 찍힘. ★2 딱지는 두께 2배 + 은박 테, ★3은 금박 테.
- 판매가: ★1 = 가격 그대로, ★2 = 가격×3 −1, ★3 = 가격×9 −2.

## 11. 유물 (v3 30종 → 20종 정리)

없어지는 시스템(전술 카드·에너지·유닛 경험치)에 묶인 유물은 빼고, 경제형 유물을 추가합니다.
- 유지 예: 전투 깃발, 철갑 견갑, 전쟁 뿔피리, 꺼지지 않는 불씨, 독샘, 피 묻은 갈고리, 눈의 구슬, 전쟁 북, 불사조 깃털(패배 1회 무효 — 게임 오버 규칙에서 가장 귀한 유물), 가시 갑옷, 사냥 호루라기, 금니

## 13. 구현 순서

1. **데이터 재구성** (`data.js`): 클래스 3, 유닛 18·스킬 30·아이템 18(등급·가격·별 스케일).
2. **경제 로직** (순수 함수, node로 테스트): 풀/상점 뽑기, 구매·판매·리롤·잠금, 창고, 합성(연쇄 포함), 레벨/이자/연승.
3. **전투 반영** (`battle.js`): 아이템 역할 효과(도약·치유 공격·소환·표식 등), 클래스 시너지, 별 스케일.
4. **준비 화면 UI**: 상점 3줄, 창고 8칸 선반, 보드 배치, 딱지 위 드래그 장착, 합성 연출, 시너지 트랙.
5. **원정 연결**: 노드=라운드, 적 편성 커브, 게임 오버·원정 기록 화면, 대장간 복제/개조, 유물.
6. **도감 개편**: 클래스·카드(클래스/등급 필터)·시너지·몬스터·유물.
7. **밸런스**: 상점 봇(합성 우선)으로 시뮬레이션 → 패배 = 게임 오버이므로 일반 95% 이상, 정예 80–85%, 보스 70–75%(합성 잘한 판 기준) 목표. 평균적인 판은 2막 보스 전후에서 끝나고, 잘 짠 판이 흑룡까지 가는 정도.

- **5막 30라운드**: 4막 얼어붙은 봉우리(설인·서리 늑대·얼음 정령·빙결 해골·설원 사냥꾼·얼음 마녀·털매머드·서리 골렘, 정예 서리 거인·설인 우두머리·얼음 기사, 보스 얼음 여왕 시엘라·설인 왕 우가), 5막 심연의 성채(악마 병사·그림자·심연 술사·지옥견·타락 기사·서큐버스·타락 사제·흉물, 정예 대악마, 보스 심연의 군주 녹스·타락한 왕 모르간). 원정대 최대 레벨 9.
- **별 가치**: 유닛 ★2 체력·공격 ×2, ★3 ×4(이전 ×1.8, ×3.2). 유닛 별에 따른 스킬 위력 ×1.7, ×2.8.
- **성능 하향**: 아이템 능력치·효과 약 30% 하향, 유물 수치 약 40% 하향, 스킬 기본 위력 ×0.85.
- **스킬마다 마나**: 칩마다 마나 막대가 따로 있고(공격·피격 마나가 모든 막대에 들어감) 찬 칩을 시전. 엔진은 `u.bars` 가 있을 때만 이렇게 동작해 다른 시안은 그대로.
- **적 강화 곡선**: 체력 = 1.2 + 0.2·라운드 + 0.009·라운드², 공격 = 1 + 0.1·라운드 + 0.0035·라운드². 일반 전투는 체력 ×0.82·공격 ×0.85로 낮춰 정예·보스가 고비가 되게 하고, 막별 보스 계수(3막 0.58, 4막 1.0, 5막 1.3)로 뒤 막을 더 어렵게.
