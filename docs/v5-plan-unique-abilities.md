# 카드 원정대 구조 개편 계획 — 유닛 고유 필살기 · 스킬 1칸 · 아이템 패시브/액티브

## 1. 목표

| | 지금 | 바꾼 뒤 |
|---|---|---|
| 유닛의 개성 | 짧은 패시브 한 줄(차이가 작다) + 특성 2개 | **고유 필살기 1개**(마나로 시전) + 특성 2개 |
| 마나 | 장착한 스킬 칩마다 막대가 따로 있고, 찬 칩부터 시전 | **필살기 전용 막대 하나** |
| 스킬 칩 | 유닛당 2칸(현자 3칸), 마나로 시전 | **유닛당 1칸**, 마나와 별개로 발동(아래 결정 2) |
| 아이템 | 능력치 + 효과 1개, 같은 전직 무기를 모으면 "전직" 시너지 | 능력치 + **패시브**와/또는 **액티브**. 전직처럼 보이지만 시너지 장치는 아님(결정 4) |

한 줄로: **유닛 = 필살기(정체성) · 스킬 칩 = 보조 기술 하나 · 아이템 = 성격을 더하는 장비**.

## 2. 먼저 정할 것 (추천안 굵게)

1. **고유 기술의 이름**: **필살기**(추천, 짧고 보드게임 카드에 잘 맞음) / 비기 / 고유기 / 특기.
   이후 이 문서는 "필살기"로 쓴다. 스킬 칩은 그대로 "스킬", 아이템 효과는 "패시브"·"액티브".
2. **스킬 칩은 무엇으로 발동하나** (마나는 필살기 전용)
   - **A. 재사용 대기시간(추천)**: 등급별 8~14초마다 자동 시전, 첫 시전 3초. 필살기와 독립이라 계산이 쉽고 시계 표시를 그대로 쓸 수 있다.
   - B. 마나 공유: 막대 하나를 필살기와 칩이 번갈아 쓴다. 단순하지만 필살기가 늦어져 정체성이 흐려진다.
   - C. 필살기 강화: 칩이 필살기에 효과를 덧붙인다(범위 +1, 화상 추가 등). 재미있지만 칩 54종을 모두 다시 써야 해서 다음 단계로 미룬다.
3. **아이템 액티브 발동 방식**: **재사용 대기시간형(예: 8초마다) + 조건형(전투 시작 시, 체력 50% 이하에서 한 번, N번째 공격마다) 섞기**(추천). 패시브는 항상 켜짐.
4. **무기 전직 시너지(9종)**: **없앤다(추천)**. 아이템 하나하나가 패시브·액티브로 역할을 바꾸므로 "같은 계열 3개 모으기"는 빼고, 시너지는 유닛 특성(성격 10종)만 남긴다. 대안: 나중에 "세트 효과"로 가볍게 되살리기.
5. **기존 유닛 패시브**: **필살기로 흡수하고 패시브는 없앤다(추천)**. 정체성이 필살기 하나에 모이게. 유닛 카드의 패시브 줄 자리에 필살기를 크게 보여 준다.
6. **성급 강화**: 공용 풀(30/25/20/15/10)에서 같은 카드를 3장(★2)·9장(★3) 모으는 데 드는 골드를 계산해 정한다. 계산 결과와 추천 배율은 `docs/v4-design.md` 의 10차 항목에 있다.

## 3. 유닛 필살기 초안 (27종)

지금 패시브의 느낌을 살려 필살기로 옮긴다. 마나는 50~120, 별(★)이 오르면 위력·범위가 오른다.

| 유닛 | 필살기 | 효과 초안 |
|---|---|---|
| 견습 검사 | 돌진 베기 | 앞 2칸을 베고 준 피해의 30% 회복 |
| 방패병 | 방패 세우기 | 자신 보호막 + 주변 1칸 적 2초 도발 |
| 용병 | 현상금 사냥 | 체력이 가장 낮은 적을 벤다. 처치하면 골드 +1(전투당 2) |
| 망치 전사 | 내려찍기 | 대상과 주변 1칸 피해 + 1.5초 기절 |
| 결투가 | 일섬 | 대상에게 확정 치명 일격, 다음 공격도 치명 |
| 광전사 | 피의 광란 | 5초간 공격 속도 +50%, 흡혈 30% |
| 기사단장 | 수호 진형 | 주변 1칸 아군 5초간 받는 피해 −25% |
| 성기사 | 신성한 망치 | 주변 1칸 적 피해, 같은 범위 아군 회복 |
| 용기사 | 용의 숨결 | 앞쪽 2×3 화염 + 화상 |
| 견습 궁수 | 집중 사격 | 같은 대상에게 화살 3연사 |
| 정찰병 | 독침 | 대상 중독 + 2초 둔화 |
| 석궁병 | 철갑 볼트 | 끝까지 관통, 방어 무시 |
| 척후병 | 기습 사격 | 가장 먼 적에게 강한 화살 |
| 매사냥꾼 | 매 부르기 | 매 소환(최대 2마리), 이미 있으면 매가 돌진 |
| 석궁 기사 | 연쇄 볼트 | 대상과 그 뒤 2칸 관통 |
| 레인저 | 마무리 사격 | 체력 25% 이하 적 처형, 아니면 큰 피해 |
| 바람 궁수 | 돌풍 화살 | 부채꼴 화살 5발 |
| 엘프 명궁 | 별빛 관통 | 세 줄 동시 관통 |
| 견습 마법사 | 마력탄 | 대상 피해(마나 적고 자주 씀) |
| 약초꾼 | 약초 뿌리기 | 주변 3×3 아군 회복 + 4초 재생 |
| 학자 | 지식의 흐름 | 주변 1칸 아군 마나 + 자신 다음 필살기 위력 증가 |
| 화염술사 | 화염구 | 대상 중심 3×3 피해 + 화상 |
| 점성술사 | 별자리 표식 | 무작위 적 셋 8초 취약 |
| 소환술사 | 골렘 소환 | 돌 골렘 소환(있으면 강화) |
| 대마법사 | 비전 폭풍 | 무작위 적에게 마력탄 6발 |
| 흑마법사 | 저주의 낙인 | 가장 센 적 둘 약화 + 피해 흡수 |
| 현자 | 성스러운 빛 | 모든 아군 회복 + 보호막 |

## 4. 스킬 칩 (1칸)

- 유닛당 1칸(현자 포함). 결정 2-A면 칩은 재사용 대기시간으로 발동한다. 기본값은 1등급 8초, 2등급 9초, 3등급 10초, 4등급 12초, 5등급 14초이고 ★이 오르면 짧아진다.
- 칸이 반으로 줄어 칩 한 장의 무게가 커지므로 위력을 약 1.3배로 올리고, 같은 역할의 칩(예: 회복류)은 합치거나 줄인다. 1등급 16종을 10~12종으로 줄이면 ★2를 만들기도 쉬워진다.
- 이전 저장: 칩이 2개 이상 끼워진 유닛은 첫 칩만 남기고 나머지는 창고로(넘치면 판 위 창고 딱지).

## 5. 아이템: 능력치 + 패시브/액티브

- 모든 아이템은 능력치에 더해 **패시브 또는 액티브 하나**를 가진다. 4등급과 보스 전용은 둘 다 가질 수 있다.
- 지금 아이템 효과의 대부분(중독 공격, 5타마다 기절, 회피 후 치명)은 그대로 **패시브**가 된다.
- 액티브는 아이템 정의에 작은 기술(모드·범위·위력 — 스킬과 같은 형식)과 발동 조건을 붙여, 전투 엔진의 `execSkill` 로 그대로 쏜다.
- 예시
  - 둥근 방패 — 패시브: 받는 피해 −5% / 액티브(10초마다): 자신 보호막 120
  - 성서 — 액티브(6초마다): 가장 다친 아군 회복
  - 사냥매 호루라기 — 액티브(전투 시작): 매 소환
  - 폭풍의 지팡이 — 패시브: 기본 공격이 주변 둘에게 번개
  - 화염 활 — 액티브(8초마다): 대상 3×3 불화살
- 전직 시너지를 없애면(결정 4) 아이템 카드의 "전직" 꼬리표 대신 "패시브 · 액티브" 꼬리표를 단다.

## 6. 화면

- **딱지 카드**: 패시브 줄 자리에 **필살기 칸**(이름·효과·마나·시전 주기)을 크게 둔다. 그 아래 스킬 1칸(대기시간 시계)과 아이템 1칸(패시브/액티브 두 줄)을 둔다.
- **전투 중**: 딱지 아래 막대는 마나(필살기) 하나만 두고, 칩·아이템 액티브는 딱지 둘레의 작은 시계 점으로 보인다.
- **상점 유닛 카드**: 패시브 문구 대신 필살기 이름과 한 줄 효과를 보인다.
- **규칙·도감**: 필살기·스킬·아이템 패시브/액티브 설명. 도감에 필살기 목록을 추가한다.

## 7. 작업 순서

1. **결정 확정**: 2장의 여섯 가지.
2. **데이터 구조**
   - 유닛에 `ult`(스킬과 같은 형식: mode·effect·cells·power·mana)를 넣는다.
   - 칩 칸 1개로 바꾼다.
   - 아이템에 `passive`·`active { trigger, cd, ...기술 }` 를 넣는다.
   - 전직 시너지를 정리하고, 저장 변환을 넣는다.
3. **전투 엔진**
   - 마나 막대를 필살기 하나로 바꾼다.
   - 칩과 아이템 액티브용 대기시간 타이머를 만든다.
   - 기존 패시브 코드는 필살기와 아이템 패시브로 옮긴다.
   - 적 유닛 스킬 처리(지금 방식)는 그대로 둔다.
4. **내용 채우기**: 필살기 27종 구현과 효과 연출(지금 쓰는 초승달 베기, 마법 구슬, 표식을 재사용), 아이템 33종 재작성, 칩 정리.
5. **화면**: 딱지 카드, 상점 카드, 전투 표시, 규칙, 도감.
6. **밸런스**
   - 측정 도구 셋: 필살기 측정(유닛별), 칩 측정(1칸 기준), 아이템 측정(패시브/액티브).
   - 기준: 1등급 유닛 필살기 ≈ 지금 1등급 스킬, 5등급 ≈ 5등급 스킬 수준.
   - 중첩 측정(같은 효과 여러 개)으로 과한 조합을 찾는다.
   - 봇을 고친 뒤(칩 1칸, 필살기 고려) 난이도를 다시 맞춘다.
7. **테스트·문서**: 지금의 화면 테스트 전부, 이전 저장 이어 하기, 설계 문서 갱신.

## 8. 위험과 대응

- **밸런스가 통째로 바뀜** → 단계마다 측정 도구로 수치를 확인하고, 난이도는 마지막에 한 번 크게 맞춘다.
- **필살기 27종 + 아이템 33종 연출 부담** → 효과 연출은 지금 있는 것(종이띠 베기, 구슬, 타일 번쩍임, 표식, 보호막 고리)을 조합해서 쓰고, 새로 만드는 건 5등급 몇 개만.
- **봇이 새 구조를 못 씀** → 봇은 "칩 1칸·아이템은 능력치 높은 것" 수준으로 단순하게 고치고, 그 기준으로 비교만 한다.
- **이전 저장** → 칩 정리와 전직 꼬리표 제거 변환을 넣고, 안 되면 "새 판 권장" 안내.
