# 향후 패치 아이디어

> 아직 구현하지 않은 아이디어 모음. 정해지면 해당 차수로 `docs/v4-design.md` 에 옮겨 적는다.

## 1. 로그라이트 메타 진행 — 부위 장비 (큰 패치)
- 원정에서 지면(어느 막이든) 보상으로 캐릭터 **부위**(머리·상체·하체)를 얻는다. 특별한 부위도 있다(예: 수염 달린 머리).
- 다음 원정을 시작하기 전에 유닛에 부위를 끼운다.
  - 예: 방패병 + 수염 달린 머리 → 체력 +10%.
  - 예: 특별한 상체 → "칸을 한 번 움직일 때마다 무작위 적에게 기본 공격 1회(100%)".
- 판을 거듭할수록 부위가 쌓여 조금씩 쉬워지는 **로그라이트** 구조.
- 부위를 바꾸면 딱지·카드 그림도 바뀌어야 하므로, 유닛 그림은 머리·상체·하체 레이어로 만든다.
- 정해야 할 것(전용/공용, 장착 한도, 지급량·희귀도, 중복 처리, 난이도 해금)과 부위 예시: `docs/plan-graphics-and-meta.md` 2장.

## 2. 그래픽 품질 올리기 (큰 패치)
- 목표는 상업 인디 게임 수준의 완성도. 엔진보다 에셋과 연출이 핵심.
- 추천 경로: 웹 2D 유지 + **Pixi.js**(WebGL 2D) 렌더러 교체, "그림 파일을 넣으면 바뀌고 없으면 지금 코드 그림" 구조.
- 순서: 스타일 가이드 → 전투 화면 하나 목표 품질로 → 렌더러 교체 → 에셋 채우기 → 애니메이션(Spine) → 사운드.
- 자세한 내용: `docs/plan-graphics-and-meta.md` 1장.

## 3. 작은 정리 거리
- 무기 스타일 9종(기사·용병·암살자·사냥꾼·저격수·도적·원소술사·사제·마도사)의 2·3개 효과를 목록으로 정리하고 다시 맞추기.
- 한 막 9칸으로 라운드 수입·경험치가 약 1.5배가 됐다 — 너무 넉넉하면 수입·경험치 조정.
- 5등급 아이템이 흡혈귀의 검 하나뿐이라, 5등급 아이템이 뜨면 항상 같은 아이템 — 5등급 아이템 추가.
- 난이도 배수(체력 2/3/4 · 공격 1.5/2.25/3)와 막별 적 강도로 실제 완주율 측정은 아직 안 함.
