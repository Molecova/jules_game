# 1~5막 적·전투 다양화 계획

상태: 구현 반영. 실제 반영 범위·검증·설계와의 차이는 `enemy-variety-implementation.md`를 참조. 아래는 초기 설계안이다.
기준: 원격 `ccr-5e12923f-aw0cjb`의 `e02f821`(2026-10-04 UTC). 로컬의 미커밋 이펙트 작업과 최신 전투 구조를 통합한 뒤 구현한다.

## 1. 현재 진단과 목표

실제 데이터와 `genEnemies()`를 확인한 결과:

- 일반 적은 막마다 8종, 총 40종. 정예 조합은 막마다 3개, 총 15개. 보스는 막마다 2종, 총 10종이다. 정예 조합 수는 정예 유닛 종류 수와 다르다.
- 일반전은 `2.2 + 0.4 × 전체 라운드` 비용 안에서 무작위 적을 최대 9기 뽑는다. 근접은 앞쪽 두 줄, 원거리는 뒤쪽 한 줄에 무작위 배치한다.
- 조합의 전술 목적, 최근 전투와의 중복 방지, 새 기믹을 먼저 가르치는 순서가 없다.
- 독버섯 주술사가 화염 폭발, 강령술사가 연쇄 번개를 쓰는 등 이름과 행동이 어긋나는 사례가 있다. 여러 막에서 같은 플레이어 스킬을 재사용한다.
- 보스는 별도 행동 스크립트와 예고 공격을 이미 갖고 있다. 일반 적의 전술적 차이를 먼저 강화하는 편이 효과적이다.

목표는 매 전투마다 **적의 핵심 위협을 읽고, 배치 또는 장비·스킬 선택을 한 가지 이상 바꾸고 싶게 만드는 것**이다. 자동전투이므로 수동 이동·회피·타깃 지정을 전제하지 않는다. 현재 존재하는 관통·범위·돌진·회복·보호막·제어 계열로 대응할 수 있어야 한다.

| 항목 | 현재 | 제안 범위 |
|---|---|---|
| 일반 적 | 40종 | 기존 40종 유지 + 신규 20종 = 60종 |
| 기존 적의 대표 행동 개편 | — | 막마다 2종, 총 10종 |
| 적 전용 대표 능력 | 공용 스킬 재사용 중심 | 신규 20종 + 개편 10종에 각 1개, 총 30개 정의 |
| 일반 전투 구성 | 비용 기반 무작위 | 막마다 6개, 총 30개 전술 템플릿 |
| 정예 전투 | 15개 조합 | 기존 15개를 각기 다른 전술 시험으로 개편 |
| 보스 | 10종 | 기존 10종의 정체성 유지, 호위·패턴 연계 강화 |

30개 능력 정의가 30개 신규 엔진 기능을 뜻하지는 않는다. 범위 피해·강화·표식·소환 등 공통 처리기를 재사용한다. 아래 시간·비율은 초기 조정값이며 확정 밸런스가 아니다.

## 3. 기존 적 10종의 개성 회복

각 막에서 2종을 고친다. 아래 10개까지 합쳐 대표 능력 정의 30개다.

| 막 | 대상 | 새 대표 능력과 대응 |
|---|---|---|
| 1 | 독버섯 주술사 | **독포자 구름**: 화염 폭발 대신 작은 범위 중독. 퍼진 배치·회복으로 대응 |
| 1 | 늑대 | **무리 사냥**: 다른 늑대가 붙어 있는 적을 공격할 때 한 번의 추가 피해, 개별 재사용 대기시간. 전열 분산으로 포위 완화 |
| 2 | 강령술사 | **뼈 일으키기**: 번개 대신 약한 해골 1기 소환. 살아 있는 소환물 최대 2기, 전투당 3회. 먼저 압박할 방향 선택 |
| 2 | 망령 | **실체화**: 짧은 회피 강화 후 회피가 사라지는 노출 구간. 무적 없음. 전열 유지와 주문 피해로 대응 |
| 3 | 새끼 용 | **작은 용숨결**: 기본 화상 대신 앞쪽 짧은 부채꼴 공격. 용 보스의 예행연습, 넓은 전열로 대응 |
| 3 | 용암 골렘 | **붕괴 열기**: 죽으면 자기 칸에 1.5초 뒤 1회 폭발. 인접 범위까지만, 추가 연쇄 폭발 없음. 원거리 마무리·방어로 대응 |
| 4 | 서리 늑대 | **서리 추격**: 둔화된 목표에 재사용 대기시간이 있는 강화 공격. 둔화 담당과 늑대 양쪽을 동시에 강화하지 않음. 전열 방어·회복으로 대응 |
| 4 | 설원 사냥꾼 | **고정 조준**: 표시한 한 대상을 오래 조준한 뒤 관통 1발. 조준 중 이동 불가. 정렬 피하기·접근·방어로 대응 |
| 5 | 그림자 | **그림자 교대**: 전투 중 한 번, 예고한 가장 먼 적 근처 빈 칸으로 이동. 순간 이동과 강한 타격을 동시에 주지 않음. 후열 호위로 대응 |
| 5 | 타락 사제 | **타락의 성가**: 한 아군을 3초간 치료하는 채널링, 시전자 제어·사망 시 중단. 짧은 빈틈 없이 계속 치유하지 않음. 집중 공격으로 대응 |

기존 적 ID는 유지한다. 소환물이 플레이어 보상·처치 골드를 무한히 생성하지 않도록 보상 제외 표시를 따로 둔다. 모든 기믹을 가진 적만 등장시키지 않고 기본 적을 섞어 읽을 여유를 준다.

## 4. 매 전투가 달라지는 구성 방식

### 막별 6개 전술 템플릿 — 총 30개

각 템플릿은 핵심 적, 보조 적 후보, 역할별 배치, 주요 위협, 대응 힌트, 예산 범위를 가진다. 핵심 적이 예산에 맞지 않으면 해당 템플릿을 뽑지 않는다. 이름만 다른 조합이 되지 않도록 핵심 전술 태그도 비교한다.

| 막 | 6개 전술 템플릿 |
|---|---|
| 1 | **방패 뒤 궁수**(전열 돌파), **북소리 돌격대**(지원 우선), **늑대 양익**(측면 호위), **독포자 군락**(분산), **덩굴 사격진**(직선 회피 배치), **도토리와 슬라임**(범위 피해 버티기) |
| 2 | **뼈 성벽**(관통), **관 운반 행렬**(증원 제어), **장송의 종**(회복원 압박), **사슬 매복**(끌기 대비), **강령 의식**(소환원 압박), **망령과 박쥐**(노출 구간 버티기) |
| 3 | **화약 운반대**(밀집 해제), **과열 수비대**(방어 전환), **분출충 포대**(공격선 분산), **불길 측면대**(후열 호위), **용의 보육장**(부채꼴 대비), **무너지는 용암벽**(사망 폭발 대비) |
| 4 | **빙벽 궁수진**(호위 돌파), **서리 사냥대**(둔화·추격), **눈표범 매복**(후열 보호), **수정 십자진**(십자 배치 해제), **매머드 전열**(근접 범위 대응), **설원 저격대**(조준선 대응) |
| 5 | **차원 증원대**(소환원+호위), **거울 결투대**(반복 타격+회복원), **고통의 계약단**(연결 대상 동시 공격), **처형 의식**(표식+지속 피해), **그림자 침투대**(후열 침투+전열), **타락 기사단**(전열 제어+채널 치유) |

1막 예시: 첫 일반전은 방패 뒤 궁수를 보고 관통·측면을 배우고, 다음 일반전은 북잡이 때문에 공격 방향을 바꾸며, 세 번째는 독포자 때문에 밀집 배치를 풀게 한다. 네 번째 이후에만 익힌 요소를 둘씩 조합한다. 서로 다른 경로를 선택해도 초반 학습 순서는 실제 경험한 전투 수로 관리한다.

### 생성 규칙

1. 막별로 템플릿 6장을 섞은 덱을 만들고 사용한 것은 제외한다. 현재 막은 6개 층이고 마지막은 보스이므로, 같은 원정·같은 막에서 일반전 템플릿을 재사용할 필요가 없다.
2. 직전 두 전투와 같은 주요 전술은 피한다. 정예까지 고려하되 후보 부족 시 이 조건만 완화하고 일반전 템플릿 중복 금지는 유지한다.
3. 핵심 적 1종을 먼저 고른 뒤 전열·공격·지원 역할을 채운다. 동일 유닛은 기본 최대 2기. 무리 템플릿만 약한 기본 적 3기까지 허용한다.
4. 한 템플릿에 배치 변형 2개(예: 좌익 호위/우익 호위)와 보조병 변형 2개를 정의한다. 좌우만 바뀐 전투를 새 전술로 집계하지 않는다.
5. 1막 초반은 주요 기믹 1개, 2~4막 일반전은 최대 2개, 5막도 강한 기믹은 최대 2개. 정예만 이미 배운 요소 3개까지 허용한다.
6. 비용에는 체력·공격력 외에 소환 예상량, 회복, 보호, 이동 교란을 포함한다. 현재 라운드 예산과 능력치 증가를 동시에 올리지 않는다.
7. 현재 플레이어 조합을 읽어서 불리한 적을 고르지 않는다. 맵 생성 시 노드별 전투를 확정하고 미리보기·새로고침·이어하기에서 유지한다.
8. 불가능한 배치, 후보 없음, 칸 부족은 검증된 기본 템플릿으로 대체한다. 기존 최대 9기 제한과 보드 점유 규칙을 유지한다.

지원만 가득한 조합, 같은 제어 기술의 연쇄 사용, 강한 소환원 2기, 두 기 이상의 반복 치유원은 일반전에서 금지한다. 치유·보호·소환이 함께 있는 조합도 금지한다. 5막의 두 기믹 결합은 같은 대상에게 회피 불가능한 폭딜을 동시에 집중시키지 않는다.

## 6. 자동전투에서의 공정성과 가독성

- 준비 화면에 전투명과 **주요 위협 2개까지** 표시한다. 예: `서리 사냥대 · 둔화 후 집중 공격 / 후열을 호위하세요`.
- 적 카드를 누르면 대표 능력, 대상 선택 방식, 첫 발동 시점 또는 마나 조건, 대응 힌트를 보여준다. 준비 화면에서 초기 예상 범위를 확인할 수 있게 한다.
- 시전은 `준비 → 예고 → 발동 → 회복` 상태로 관리한다. 예고 중 취소 가능한 기술은 기절·시전자 사망으로 취소한다. 이미 던진 폭탄과 사망 폭발은 시전자 사망 후에도 완료하며 카드에 명시한다.
- 예고는 0.8~1.5초를 시작값으로 삼되 강한 단일 표식은 2초를 준다. 자동전투에서 예고는 수동 회피 요구가 아니라 공격 원인과 대응을 이해시키는 장치다.
- 전체 빙결·침묵은 추가하지 않는다. 강제 이동은 최대 1칸, 빈 칸만 허용하고 길막·겹침을 방지한다. 반복 제어에는 대상별 짧은 재적용 제한을 둔다.
- 소환은 시전자별 상한과 전투 전체 상한을 모두 적용한다. 소환된 적은 추가 소환 능력을 갖지 않는다. 자리가 없을 때 무한 재시도하거나 강제로 밀어내지 않는다.
- 같은 강화는 지속시간 갱신만, 기존 보호막 최대 체력 50% 상한 유지. 피해 전이에는 재전이 금지 표식을 붙여 계약 루프를 막는다.
- 도약 목표는 준비 중 현재 배치에 맞춰 표시하되 전투 시작 시 고정한다. 표시와 실행이 달라지는 숨은 타깃 변경을 하지 않는다.
- 역할별 실루엣을 구분한다: 넓은 방패, 긴 창, 큰 북, 낮은 짐승, 높은 지팡이. 색깔 변경만으로 새 유닛을 만들지 않는다.
- 기존 오린 종이·잉크 스타일을 유지한다. 선·십자·고리·연결선·발자국·파열의 공통 연출을 사용하고, 피해 범위와 장식 입자를 분리한다. 색 외에도 무늬와 모양으로 위협을 구분한다.

현재 `makeFoe()`는 `GD.SKILLS`에서 적 스킬을 찾으므로 플레이어 칩 배열에 적 능력을 추가하는 것만으로는 동작하지 않는다. `v4/enemies4.js`에 별도 네임스페이스(`enemy_*`)를 사용하고 상점·보상 풀에는 넣지 않는다.

기존 일반 적은 마나 발동을 유지할 수 있고, 새 전용 행동은 고정 대기시간 또는 1회 조건으로 실행한다. 적마다 첫 시전 시간을 달리해 여러 기가 한 프레임에 동시에 강한 기술을 쓰지 않게 한다. 어느 방식이든 카드에 표시하고 전투 속도·일시정지·건너뛰기에 동일한 시뮬레이션 시간을 사용한다.

현재 공용 엔진은 `Math.random()`을 사용한다. 최소 1차에는 조우 생성 전용 시드 난수를 도입해 전투 생성과 시각 효과 난수를 분리하고, 생성된 적 배치 자체도 저장한다. 전투 전체 결정성을 보장한다고 가정하지 않는다. 자동 회귀 측정에서는 통제된 난수로 동일 조건을 재현한다.

기존 저장은 이미 생성된 `R.enemies`와 진행 중 전투 구성을 보존한다. 다음 미방문 노드부터 새 생성기를 쓰며, 저장 데이터에 콘텐츠 버전·조우 덱·소비 이력을 추가한다. 기존 유닛 ID·스킬 참조가 사라져 저장이 깨지지 않도록 검증한다.

## 8. 구현 순서와 눈으로 볼 수 있는 결과물

1. **기반 통합 및 기준 측정**: 최신 고유기·칩·아이템 액티브 구조와 미커밋 VFX를 통합. 기존 저장·전투 회귀 확인, 고정 구성으로 막별 전투 시간·피해·승률 측정.
2. **1막 전체를 먼저 완성**: 신규 4종 + 기존 2종 개편 + 전투 6개 + 적 카드·범위·연출. 같은 아군의 배치 전후를 비교하는 재생 시안과 짧은 GIF/영상 제공. 이 단계로 다양화 방식이 실제로 읽히는지 확인.
3. **2·3막 확장**: 신규 8종 + 기존 4종 개편 + 전투 12개. 소환·회복·강제 이동·사망 폭발·방어 전환 처리 추가. 각 막 대표 전투를 시안에 추가.
4. **4·5막 확장**: 신규 8종 + 기존 4종 개편 + 전투 12개. 둔화 연계·후열 도약·피해 전이·표식 공격 추가. 제어와 지원의 조합 제한 검증.
5. **정예·보스·전체 원정 조정**: 기존 정예 15개와 보스 10종의 연결, 난이도별 비용·능력치 조정, 저장 호환·모바일 가독성·성능 확인.

시안은 실제 전투 처리기를 사용한다. 버튼은 `전투 선택 / 재생 / 다시 보기 / 0.5·1·2배속 / 범위 표시 / 배치 A·B 비교`로 구성한다. 그림만 움직이는 시안과 실제 게임 피해가 어긋나지 않게 한다. 실행 가능한 HTML과 캡처를 함께 제공한다.

## 9. 완료 기준과 검증

- 데이터: 신규 적 20종·개편 10종·대표 능력 30개·일반전 30개가 모두 참조 오류 없이 생성된다. 각 일반전은 유효한 시작 배치, 예산, 적 수 상한을 만족한다.
- 생성: 막당 1,000개 시드로 모든 템플릿의 도달 가능성, 원정 내 일반전 템플릿 중복 0건, 핵심 적 누락 0건, 금지 조합 0건을 검사한다.
- 학습: 1막 첫 세 번의 일반전은 서로 다른 주요 위협을 제시한다. 맵 경로·이벤트 방문 때문에 학습 순서가 뒤집히지 않는다.
- 대응: 템플릿마다 배치만으로 가능한 대응 하나 이상과 장비·스킬을 이용하는 대안 하나 이상을 문서화한다. 최소 3개 대표 아군 구성으로 잘못된 배치와 대응 배치를 비교하고 개선 효과가 나타나지 않는 템플릿을 수정한다. 특정 희귀 카드 보유를 필수로 하지 않는다.
- 전투 정확성: 소환 상한·시전 취소·이미 발사된 폭탄·사망 폭발·피해 전이 루프·이동 칸 점유·사망 후 연결 해제·제어 재적용 제한을 직접 검증한다.
- 속도와 저장: 같은 통제 난수에서 0.5/1/2배속·건너뛰기의 결과가 일치하고, 메뉴 정지 중 타이머가 진행되지 않는다. 이어하기로 적 구성과 조우 이력이 바뀌지 않는다.
- 균형: 최신 버전의 같은 조건을 기준으로 비교한다. 보통 난이도 일반전 시간 중앙값은 우선 15~30초를 조정 목표로 두되 기준 측정 후 확정한다. 80초 제한에 도달하는 회복·소환 교착을 제거한다. 새 기믹 때문에 쉬움 첫 막 통과율이 기준 대비 5%p 이상 하락하면 조사한다.
