# 적 다양화 · 기본 공격 개별화 구현 기록

기반: 원격 `e02f821`의 고유기·칩 1칸·아이템 액티브 구조와 기존 로컬 VFX를 통합했다.

## 반영 내용

- 일반 적 40 → 60종. 막마다 신규 4종, 기존 2종의 행동 개편. 적 전용 능력 30개는 플레이어 상점에 들어가지 않는다.
- 막마다 6개, 총 30개 일반전 템플릿. 같은 막 내 일반전 중복 방지, 역할별 배치, 예산·최대 수 제한, 최근 주요 위협 회피. 1막 첫 세 일반전은 방패·북잡이·독포자 순으로 학습한다.
- 정예는 막별 3개 조합으로 다시 구성하고 보스는 기존 행동 스크립트를 유지하면서 호위를 변형했다.
- 소환 상한, 시전자 소유권, 소환물 처치 보상 제외, 시전 취소, 사망 후 폭발, 피해 전이 재귀 방지, 강제 이동 점유 검사를 구현했다. 마지막 적이 사망해도 이미 예약된 폭발은 끝난 뒤 승리 판정한다.
- 전투 준비 화면에 조합명·대응 힌트, 적 카드에 능력 설명을 표시한다. 전투 중 예고 칸·진행 고리·표식·계약 연결선을 그린다.
- 신규 적은 기존 종족 초상화 위에 방패·북·관·사슬·폭탄·수정·거울·낫 등 별도 실루엣을 추가한다.
- 궁수 9종과 마법사 9종에 투사체 모양·색·잔상·명중 효과를 각각 정의했다. 기본 공격 피해·사거리·투사체 속도는 바꾸지 않았다. 실제 공격이 근접으로 바뀌는 무기는 기존 동작을 유지한다.
- 전투 준비 중 구매·배치·적 구성을 저장하고 이어하기에서 준비 화면을 복원한다. 조우 난수 시드·사용한 조합·생성 결과가 저장된다. 지도 저장 호환도 유지한다.
- 일반 재생·배속·건너뛰기·시뮬레이션은 1/60초 전투 단위로 처리한다. 이펙트가 전투 난수를 소비하지 않도록 새 투사체 렌더러는 순수한 시각 처리로 작성했다.
- 기존 9종 스킬 시안의 부활은 삭제된 스킬이므로 현자의 성스러운 빛으로 교체했다.

## 파일과 실행

- `v4/enemies4.js`: 적·능력 데이터.
- `v4/encounters4.js`: 전투 조합 및 저장 가능한 생성기.
- `v4/enemy-combat4.js`: 전용 능력 처리, 예고·연결 효과.
- `v4/enemy-art4.js`: 신규 초상화 소품과 실루엣.
- `v4/projectiles4.js`: 18종 기본 공격 프로필과 렌더러.
- `concepts/v4-enemy-encounters.html`: 실제 전투 엔진으로 30개 전투 재생, 분산/밀집 배치 비교, 속도·일시정지, 기본 공격 18종 갤러리.

```sh
python3 -m http.server 8000
node --test tests/*.test.cjs
node tests/browser-enemies.cjs
node tests/browser-smoke.cjs
python3 scripts/build-skill-preview.py /tmp/jules-preview
```

브라우저 테스트에는 Playwright와 `/usr/bin/chromium`이 필요하다. 테스트 캡처는 기본 `/tmp/jules-enemy-preview`, `PREVIEW_OUTPUT`으로 변경한다. 배포용 HTML은 모든 로컬 스크립트를 포함한다.

## 검증

- 5개 막 × 1,000개 시드: 일반전 총 25,000개에서 비용·점유·중복·핵심 적·저장 복원을 검사. 모든 일반전 템플릿에 도달. 정예·보스 10,000개 추가 배치 검사.
- 30종의 신규/개편 적 각각 20초 전투에서 유효한 체력·좌표·점유와 능력 발동을 확인.
- 표식 시전 중 기절 취소, 시전자 사망 뒤 폭탄 발동, 마지막 적의 사망 폭발, 소환 상한·보상 제외, 계약 전이·사망 해제, 당기기·도약 점유를 확인.
- 18종 투사체를 난수 호출을 금지한 상태에서 렌더링하고 피해 값이 변하지 않는지 확인.
- 기존 대표 스킬 8종의 ★1/★3 이펙트 전후 전투·난수 동등성과 실제 대상 메타데이터, 운석 지연, 이펙트 상한·해제를 확인.
- Chromium에서 실제 전투 시안 30개를 각각 12초 진행, 모바일 390px 가로 넘침 없음, 9종 스킬 시안 정상, 전투 준비 저장·새로고침·이어하기 동일, 실제 게임 건너뛰기 완료. 자바스크립트 예외 없음.
- 원정 생성·상점 구매·전투·지도 저장·이어하기와 기존 v3 진입을 별도 스모크 테스트로 확인.

## 초기 설계와의 차이 및 남은 조정

- 노드 진입 시 조합을 생성하고 저장한다. 맵 생성 시 모든 분기 노드의 조합을 미리 고정하는 방식은 사용하지 않았다. 같은 저장의 이미 방문한 노드는 같은 결과를 반환한다.
- 준비 화면에서 선택한 적의 현재 배치 기준 예상 범위를 표시하고, 도약 적은 후열 목표 연결선을 표시한다. 일반 예고의 대상은 전투 중 이동·체력 변화에 따라 달라질 수 있다.
- 호위는 가까운 동료 기준이다. 방향별 후방 호위 전용 AI 대신 기존 경로 탐색을 유지했다. 보스 스크립트 자체의 재설계는 하지 않았다.
- 피해 전이는 대상의 실제 체력 피해를 기준으로 계산하고, 전이받는 유닛의 방어를 적용한다. 정확히 원래 공격의 25% 고정 피해는 아니다.
- 전체 전투 난수의 저장·재생 기능은 도입하지 않았다. 조우 생성의 결정성과 시각 효과의 난수 독립성을 검증했다.
- 난이도별 500회 완주 봇 측정과 기기별 성능 벤치마크는 실행하지 않았다. 현재 수치는 초기 구현값이며 장기 진행 난이도는 플레이 결과에 맞춰 조정할 수 있다.
