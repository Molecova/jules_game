# 대못·정신없는 활·버팀목·환승 구현 기록

2026-10-07. `Molecova/jules_game`, `ccr-5e12923f-aw0cjb`. 시작 전 최신 `bd0117b`를 pull하고 구현했다. 기존 아이템·칩을 유지하면서 무기 2개와 칩 2개를 추가했다.

대못은 조건을 만족해야 강화되는 초중반 무기다. 버팀목은 생존과 대못의 고정 상태를 지원한다. 정신없는 활은 높은 공격력 대신 집중 공격을 잃는다. 활과 환승을 함께 쓰면 다른 적이 사거리 안에 있는 동안 반복적인 추가 피해를 낼 수 있어 환승을 최고 등급에 배치했다. 환승의 별 계수는 전용 표를 사용한다.

## 발동 규칙

- **대못:** 같은 칸에 정지한 시간 2초를 누적한다. 이동 애니메이션 중에는 누적하지 않는다. 충전 후 기본 공격·고유기·칩·지속 피해·반사 등 모든 피해에 `1 + 0.3 × min(2, ifxK)`를 곱한다. 강화 여부는 피해가 적용되는 순간에 읽는다. 이동·밀치기·도약·순간이동은 즉시 초기화한다. 같은 프레임 안에서 왕복해도 초기화된다. 기존 제작자 시너지의 아이템 배수도 반영하되 최대 증가율 +60%를 유지한다.
- **버팀목:** 자신을 4초간 이동 불가로 만들고 시전 1·2·3·4초 후에 각각 보호막을 준다. 즉시 보호막은 없다. 재사용 대기시간은 12 / 10.8 / 9.6초다. 보호막은 `100 × 칩 별 배수 × 유닛 스킬 별 배수 × 스킬 위력 × 치유/보호막 배수`를 사용한다. 기존 최대 체력 50% 보호막 상한과 치유 차단을 적용한다. 재시전은 하나의 타이머를 다시 시작한다. 이동 중 시전하면 이미 예약된 칸에 도착한 뒤 고정된다. 일반 이동 불가와 마찬가지로 강제 밀치기·순간이동은 가능하며 대못은 초기화된다.
- **정신없는 활:** 기본 공격을 현재 대상에게 발사한 뒤 사거리 안의 다른 살아 있는 적을 다음 대상으로 선택한다. 현재 대상·설치물·죽은 적·사거리 밖 적은 후보에서 제외한다. 후보가 없으면 유지한다. 도발이 살아 있는 동안에는 도발 대상을 따른다. 무작위 선택은 전투의 `cb.random()`을 사용한다. 이미 발사된 투사체의 대상은 바꾸지 않는다.
- **환승:** 실제 기본 공격 대상이 직전 기본 공격 대상과 다를 때 새 대상에게 추가 피해를 한 번 적용한다. 최초 대상 선택, 같은 대상 연타, 공격 없이 이루어진 AI 탐색에는 발동하지 않는다. 직전 적이 죽고 새 적을 공격하는 경우에도 발동한다. 다른 무기를 쥐어도 사용할 수 있다. 재사용 대기시간·마나 비용이 없다. 장비·시너지·유닛 별로 증가한 현재 공격력을 사용하며 스킬 위력·스킬용 유닛 별 배수·치명타 배수는 곱하지 않는다. 방어·피해 감소·취약·보호막·무적과 기존 흡혈은 정상 적용한다. 추가 피해는 별도 `transfer` 피해 종류로 처리해 기본 공격/스킬 적중 효과를 반복 발동하지 않는다.

## 연결과 연출

`data4.js`의 ITEMS·SKILLS·기사/사냥꾼 스타일에 등록해 상점, 합성, 도감, 저장 호환 구조를 사용한다. `game4.js`의 성급표는 실제 수치와 발동 조건을 표시한다. 전투 전용 타이머·직전 대상은 저장 파일에 넣지 않는다.

| 이벤트 / 상태 | 연출 |
|---|---|
| `p_nailAnchor` | 고정 완료 도장. 고정 중 유닛 발밑에 잉크 도장과 두 개의 못 표시 |
| `brace` | 자신에게 수호 진형 연출·이동 불가 표시 |
| `p_braceShield` | 실제로 보호막이 증가한 순간에 파란 보호막 연출 |
| `p_restlessTarget` | 다음 대상의 금색 과녁 |
| `transfer` | 새 대상에 관통 화살·금색 추가 피해 숫자 |

Canvas 연출은 좌표·상태를 읽으며 전투 난수를 사용하지 않는다. 대못과 버팀목은 유닛당 타이머 하나를 재사용한다. 이동 직후 같은 프레임의 피해까지 초기화를 반영하도록 엔진 `moveTo`·`teleport`에 선택적인 `onMove` 훅을 추가했다. 기존 훅이 없는 버전은 기존 경로로 동작한다. 기존 48개 이펙트 상한, 시뮬레이션/빨리 넘기기 억제, 움직임 감소 설정을 유지한다.
