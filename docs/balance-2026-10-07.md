# 실제 원정 플레이를 통한 v4 밸런스 조정

2026-10-07 · 저장소 `Molecova/jules_game` · 브랜치 `ccr-5e12923f-aw0cjb`

보통 난이도에서 같은 자동 플레이와 같은 12개 원정 시드를 3가지 플레이 성향에 적용했다. 기존 버전은 36회 중 완수 0회, 수정 버전은 10회(27.8%)였다. 수정 버전의 최종 보스 직접 처치는 8회다. 어려움은 별도 45회 중 2회 직접 처치했고, 지옥은 45회 중 완수 0회였다. **보통의 진행 불가능에 가까운 보스 장벽은 낮췄지만, 지옥의 클리어 가능성과 최종 균형은 검증되지 않았다.** 아래 수치는 사람의 승률이 아니라 제한된 의사결정 규칙을 가진 자동 플레이의 관측 결과다.

## 1. 사람의 플레이 조건을 재현하는 방법

완성된 ★3 부대를 임의로 만들어 보스와 싸우는 방식으로는 상점 운, 골드, 창고, 합성 비용, 성장 중의 패배를 평가할 수 없다. 새 원정의 빈 부대에서 출발해서 다음 과정을 실제 게임 코드로 수행했다.

- 현재 화면에서 갈 수 있는 경로를 선택한다. 현재 막의 공개 지도는 보되 다음 막이나 아직 생성되지 않은 전투는 보지 않는다.
- 실제 상점 카드만 구매한다. 구매 가격, 리롤 비용, 이자, 출전 제한, 클래스별 장착 제한, 창고 제한을 그대로 적용한다.
- 같은 카드 3장 합성, 경험치 구매, 장비 교체, 퇴역 유닛의 장비 회수, 판매를 실제 게임 함수로 처리한다.
- 전위와 후위를 나누고 원거리 딜러를 확보한다. 공개된 현재 보스 설명을 보고 제어·회복 방해 스킬을 우선할 수 있다.
- 이벤트·보물·전리품은 화면에 나온 선택지를 실제로 누른다. 선택 후 무작위 결과를 미리 조회하지 않는다.
- 전투는 실제 전투 엔진에서 한 번만 실행한다. 결과를 보고 이전 상점·배치로 돌아가 재시도하지 않는다.

의사결정 모듈에는 공개 데이터와 현재 소유 카드의 읽기 전용 복사본만 전달한다. 게임 RNG, 전투 시드, 저장된 미래 편성, 이벤트의 무작위 결과는 전달하지 않는다. 플레이 성향의 작은 선택 오차에는 게임 RNG와 별개인 난수를 사용한다.

| 자동 플레이 성향 | 일반 노드 리롤 상한 | 저축 기준 | 주요 판단 |
|---|---:|---:|---|
| `novice` 단순 강화형 | 1 | 0골드 | 눈앞의 능력치·합성, 낮은 시너지 고려 |
| `balanced` 혼합 성장형 | 3 | 10골드 | 전위·딜러 확보, 레벨·장비·합성 병행 |
| `synergy` 조합 추구형 | 4 | 20골드 | 현재 가능한 시너지와 장기 합성 프로젝트 |

저축 기준은 1막·보스·직전 전투의 잔여 체력이 낮을 때 풀린다. 혼합 성장형·조합 추구형은 보스 앞에서 30골드 이상 있을 때 추가 리롤을 최대 4번 허용한다. 한 노드의 상점 판단은 최대 40회, 후보 합성 프로젝트는 최대 2종이다. 모든 조합을 계산해서 최적 해답을 구하지 않는다.

각 행동 뒤 골드 비음수, 카드 UID 중복 금지, 출전·장착·배치 제한, 카드 풀과 소유 카드의 총량 보존을 검사했다. 원정마다 구매·판매·장착·경로·골드 변화와 모든 전투의 부대·성급·장비·피해량을 저장했다. 최종 162회 비교·검증에서 이 제약 검사 56,404회를 통과했다.

전투만 1/60초 단위로 빠르게 진행하며 애니메이션을 생략한다. 전투 계산·승패·보상·저장은 실제 흐름과 같다. 별도 테스트에서 기존 단일 전투 시뮬레이터와 실제 전투의 승패·시간·잔여 체력이 일치하는 것도 확인했다. 이 시뮬레이터는 플레이의 의사결정에 사용하지 않는다. 스크린샷의 플레이 시간이 0분인 것은 이 가속 실행 때문이다.

## 2. 조정 기준과 실제 변경

첫 보스에서 대부분의 원정이 끊기는 구조를 완화하고, 2~5막에서 성장과 조합의 차이가 드러나도록 했다. 초기 보정 중 보통 완수가 30회 중 22회이고 첫 보스 이후의 보스전이 모두 승리하는 후보는 너무 쉬워 제외했다. 이후 막별 성장과 보스 계수를 조정했다. 최종 비교에는 조정에 사용한 시드와 다른 시드를 사용했다. 사람의 목표 승률을 이 자동 플레이의 수치로 단정하지 않는다.

### 막별 병력과 전반·후반 변화

| 막 | 전반 일반전 | 후반 일반전 | 합산 위력 예산 전반 → 후반 |
|---|---:|---:|---:|
| 1 | 4~5기 | 5~6기 | 2.2 → 3.6 |
| 2 | 8~10기 | 10~12기 | 3.8 → 5.0 |
| 3 | 3~4기 | 3~4기 | 3.6 → 4.6 |
| 4 | 5~6기 | 6~7기 | 4.5 → 5.5 |
| 5 | 3~4기 | 10~12기 | 3.2 → 6.5 |

한 막은 9노드다. 지도 층 인덱스 0~3은 전반, 4~7은 후반, 마지막은 보스다. 첫 원정 첫 전투는 위력 예산 1.7을 사용한다. 일반전의 각 적에게 `합산 위력 예산 / 등장 수`를 곱하므로 물량전이 모두 강한 적 12기의 집중 공격이 되지 않는다. 이것은 HP·공격력·스킬 위력 배율의 합이며, 서로 다른 적의 실제 HP·초당 피해가 같은 합계라는 뜻은 아니다.

편성 템플릿은 전반 3종·후반 3종을 우선하며, 이미 사용한 편성이면 남은 편성에서 선택한다. 핵심 적과 보조 적을 반드시 포함하고 같은 일반 적은 최대 3기까지 등장한다. 보스·정예는 기존 3기 편성을 유지한다. 기존 저장에 이미 확정된 편성은 다시 뽑지 않는다.

### 적의 성장과 보스

막 안의 성장은 노드당 ×1.08에서 ×1.045로 낮췄다. 막별 일반·정예·보스의 계수는 별도로 수정했다. 일반 적의 2막 공격 계수는 1.469 → 1.6159로 올리고, 물량에 따른 개체 배율로 조정했다. 모든 적을 일률적으로 약하게 만들지는 않았다. 원래 공격 속도·방어·특수 패턴과 아군 카드의 능력치는 유지한다.

아래는 보통 난이도에서 해당 막의 마지막 노드 기준 **보스 본체**의 HP와 기본 공격력이다. 공격력은 반올림했고 호위·소환수·패턴 피해는 포함하지 않는다.

수정 전에는 구매·합성을 거친 부대가 사실상 보스에서만 탈락했다. 후반 보스의 기본 공격과 소환·광역 패턴이 함께 누적되는 부담이 특히 컸다. 높은 체력을 무작정 유지하면서 공격 계수까지 크게 올리는 구조를 줄였다.

### 난이도와 성장 자원

| 난이도 | 적 HP·공격·스킬 상대 배수 | 시작 골드 | 기본 노드 수입 | 노드 경험치 |
|---|---:|---:|---:|---:|
| 보통 | ×1 | 6 | 5 | 2 |
| 어려움 | ×1.5 | 8 | 6 | 3 |
| 지옥 | ×2 | 14 | 8 | 4 |

첫 노드는 시작 골드만 제공하며 노드 수입·경험치는 둘째 노드부터 지급한다. 이자·유물·전투 보상은 별도다. 기존 어려움·지옥의 수입 -1을 제거하고, 더 강한 적에 맞는 초기 구매와 레벨 성장 자원을 제공한다. 난이도 선택·확률 안내·도움말도 실제 값에 맞췄다.

이전 요청의 **보통 배수 ×1 정규화는 유지**한다. `FOE.base`의 HP ×2·공격 ×1.5도 그대로다. 이번에는 새 요청에 따라 그 기준 위의 밸런스 계수를 실제로 조정한 것이다. 정규화 자체가 몰래 전투 값을 줄이지 않는다는 동치 테스트는 새 기준에도 계속 적용한다.

### 제어 스킬과 보스의 규칙 일치

보스가 기절·침묵 중에도 특수 능력을 사용하던 문제를 수정했다. 제어 상태에서는 새 패턴을 사용하지 않고, 예고 중인 보스 공격도 취소된다. 이미 떨어진 피해를 되돌리지는 않는다. 제어 중에도 재사용 대기시간은 흐르므로 짧은 기절로 타이머를 영구 정지시키지 않는다. 속박·둔화는 능력을 취소하지 않는다. 보스 설명에도 이 대응 방법을 추가했다.

## 3. 최종 측정 결과

기존 기준은 커밋 `9f798db8d2e10a12e7e20a19a72d9130a7562d9c`다. 기존·수정 버전은 같은 최종 플레이 정책을 사용했다. 기존 버전에는 이미 존재하는 실제 입력 함수의 테스트용 export만 추가했다. 두 버전 모두 숨겨진 상태 조회나 가상 카드 지급은 없다. 보통 비교 시드는 `51000001 + i × 7919`, 각 성향 `i=0..11`이다.

| 성향 / 보통 | 기존 완수 | 수정 완수 | 수정 최종 보스 직접 처치 | 수정 완수율의 95% 구간 |
|---|---:|---:|---:|---:|
| 단순 강화형 | 0/12 | 4/12 | 3/12 | 13.8~60.9% |
| 혼합 성장형 | 0/12 | 5/12 | 4/12 | 19.3~68.0% |
| 조합 추구형 | 0/12 | 1/12 | 1/12 | 1.5~35.4% |
| 합계 | 0/36 | 10/36 | 8/36 | 성향별 구간을 위에 표시 |

완수 중 2회는 불사조 깃털로 마지막 패배를 넘겼으므로 직접 처치와 분리했다. 제한시간 종료 후 잔여 체력 비율로 승리하는 경우도 직접 처치에 넣지 않는다. 기존 결과의 첫 보스 직접 승리는 13/36, 두 번째 보스 직접 승리는 1/13이었다. 수정 결과는 각각 33/36, 25/32로 개선됐다. 후반에는 여전히 보스·정예·일반전에서 탈락한다.

보통 보스전 부대의 평균 성급은 1막 약 1.5~1.6성, 5막 약 2.1~2.3성이었다. 임의로 만든 전원 ★3 부대의 결과가 아니다. 조합 추구형이 단순 강화형보다 좋은 결과를 보장하지 않았다는 점도 숨기지 않는다. 제한된 정책의 조합 평가·저축 판단이 항상 좋은 선택은 아니다.

고난도는 별도 시드 `54000001 + i × 7919`, 각 성향 `i=0..14`로 측정했다.

| 성향 | 어려움 완수 / 직접 처치 | 지옥 완수 / 직접 처치 |
|---|---:|---:|
| 단순 강화형 | 1/15 / 1/15 | 0/15 / 0/15 |
| 혼합 성장형 | 1/15 / 1/15 | 0/15 / 0/15 |
| 조합 추구형 | 0/15 / 0/15 | 0/15 / 0/15 |
| 합계 | 2/45 / 2/45 | 0/45 / 0/45 |

**지옥은 해결 완료 판정을 내리지 않는다.** 45회 모두 실패했고 5막 도달 사례도 없다. 0승이 수학적으로 클리어 불가능하다는 증거는 아니지만, 플레이 가능한 최고 난이도로 검증됐다는 증거도 없다. 어려움의 2승 역시 충분한 표본은 아니다.

다음 검증은 실제 사람에게 현재 버전의 보통·어려움을 플레이하게 하고 구매·배치·실패 지점을 비교하는 것이다. 특히 자기 주변 범위 스킬과 방향 스킬의 배치 판단, 장비별 효과 조합은 이 정책의 약점이다. 이 판단을 보완한 플레이 및 사람의 기록에서 지옥의 같은 병목이 확인되면 지옥 전용 성장 자원이나 적 배수를 추가 조정해야 한다. 자동 플레이를 실제 사람과 같다고 주장하거나, 지옥이 쉬워질 때까지 모든 난이도의 적을 계속 낮추지는 않았다.

## 4. 검증·근거·재현

- Node 회귀 테스트 **332개 통과**. 5,000개 시드의 막별 편성·위력·저장 일관성, 모든 적의 난이도 배수, 모든 보스의 제어 중단·해제 후 재개를 포함한다.
- 브라우저에서 실제 전투와 단일 전투 시뮬레이션의 동치, 같은 원정 시드의 행동·결과 결정성, 합성·장비·골드·카드 풀·출전 제한을 검증했다.
- 최종 162회 원정의 JavaScript 예외와 브라우저 콘솔 오류 **0**. 로컬 리소스 오류 0. 외부 Google 폰트는 측정 환경에서 차단해 기본 폰트를 사용했다.
- 360×640·390×844 화면에서 시작·구매·전투·저장 재개와 난이도 선택을 확인했다. 원정 자동 플레이는 390×844에서 실행했다.
- 기존 원정 흐름·버그 수정 브라우저 검사도 통과했다. 기존 `browser-run.cjs`의 강화 부대는 화면 전환 검사에만 사용하고 밸런스 근거에 넣지 않았다.
