## 검증

- `node --test tests/*.test.cjs`: 기존 55개 + 새 6개, 총 **61개 통과**.
- 기존 `browser-smoke.cjs`, `browser-enemies.cjs`: 통과. 공용 엔진을 사용하는 이전 버전 스모크도 유지.
- `browser-bugfixes.cjs`: 이벤트 12종, 일반·정예·보스 보상, 매복 3종, 저장 손상·백업·저장 실패, 제작 수량, 전투 난수 독립성, 모달 일시정지·키보드, 4개 화면 크기 검사.
- `browser-scenes.cjs`: 장면 16종 × 2개 폰 화면 = **스크린샷 32장**. 390×844/DPR 2 및 360×640/DPR 3에서 시트 잘림·스크롤 없이 표시.
- `browser-run.cjs`: 강화한 시험 부대로 1~5막 **30개 노드·보스 5회** 진행. 지도와 확정 결과마다 새로고침·이어하기, 마지막 완수 기록 1회, 종료 후 본 저장·백업 삭제 확인. 이는 진행 연결 검사이며 실제 난이도나 승률 검증이 아니다.
- 추가 브라우저 회귀 검사에서 JavaScript 예외 **0건**. 장면·추가 검사에서는 외부 폰트 CSS를 빈 응답으로 대체했다. 기존 스모크의 외부 폰트 요청 실패와 JavaScript 예외를 구분한다.
- 가로 화면 844×390 및 640×360, 세로 화면 390×844 및 360×640에서 보드·상점 겹침 없음.

재실행 방법은 README의 v4 회귀 검사 명령을 참고한다. 기본 브라우저 증거 경로는 `/tmp/jules-bugfixes`이며 `BUGFIX_OUTPUT`으로 변경할 수 있다.
