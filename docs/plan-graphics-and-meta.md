# 다음 단계 계획(저장용) — 그래픽 품질 · 로그라이트 메타 진행

> 2026-10-07 대화에서 정리. 아직 구현하지 않았다.

## 1. 그래픽 품질 올리기

목표는 "Inscryption 같은 스타일"이 아니라 **상업 인디 게임 수준의 완성도**. 그 수준을 가르는 건 엔진보다 그림 자원(에셋)과 연출이다. 지금은 모든 그림을 코드로 그려서(딱지·초상화·이펙트 = 캔버스 도형) 엔진을 바꿔도 한계가 있다.

### 완성도를 만드는 요소
1. 아트 디렉션(색·선·질감 규칙을 정한 스타일 가이드)
2. 직접 그린 에셋: 유닛 일러스트, 카드 틀, 배경, UI 부품, 아이콘
3. 애니메이션: 대기·공격·피격·사망(Spine 같은 뼈대 애니메이션 또는 프레임)
4. 이펙트와 손맛: 파티클, 셰이더(빛 번짐·왜곡·디졸브), 화면 흔들림, 타격 멈춤, 카메라 연출
5. 조명·후처리: 색 보정, 블룸, 비네트
6. 사운드: 효과음, 음악, 환경음

### 기술 선택
- **추천: 웹 2D 유지 + Pixi.js(WebGL 2D)**. 지금 캔버스 그리기 자리에 들어가며 전투·데이터·저장 코드는 그대로 둔다. 셰이더 필터, 파티클, Spine 런타임 지원. 휴대폰 브라우저·itch.io 그대로.
- 대안: Godot 4 / Unity 이전 — Steam·앱스토어·3D 연출이 목표일 때. 게임 코드를 전부 옮겨야 함.

### 에셋 확보
- AI 이미지 생성 + 사람이 다듬기(스타일 가이드·기준 그림 고정, 배경 제거·선·색 통일) — 혼자 개발할 때 가장 현실적.
- 에셋 팩 구매(itch.io, Unity Asset Store, Kenney 등) 또는 외주.
- 도구: Krita/Procreate, Aseprite, Spine, Blender, FMOD/sfxr.

### 진행 순서
1. 참고 이미지 3~5장으로 스타일 가이드
2. 전투 화면 하나만 목표 품질로(유닛 3·적 3·배경·이펙트 몇 개)
3. Pixi.js 렌더러로 교체 + "그림 파일을 넣으면 바로 바뀌고, 없으면 지금 코드 그림으로" 구조
4. 나머지 에셋 → 애니메이션 → 사운드

**주의**: 아래 2장의 부위 장비를 하려면 유닛 그림이 **머리·상체·하체 레이어로 나뉜 구조**여야 한다(부위를 바꾸면 그림도 바뀌게). 에셋을 만들 때부터 이 구조로 만든다.

## 2. 로그라이트 메타 진행 — 부위 장비

### 아이디어(사용자 원안)
- 원정에서 지면(1·2·3막 어디서든) 보상으로 **캐릭터 부위**를 얻는다. 카드 속 캐릭터를 **머리 · 상체 · 하체**로 나눈다.
- 특별한 부위가 있다. 예: **수염 달린 머리**.
- 다음 판을 시작하기 전에 유닛에 부위를 끼운다. 예: 방패병에 수염 머리 → 체력 +10%.
- 특별한 상체는 특수 능력을 가진다. 예: **칸을 한 번 움직일 때마다 무작위 적에게 기본 공격 1회(100% 피해)**.
- 판을 거듭할수록 조금씩 강해져 사실상 난이도가 내려가고, 전리품이 쌓인다 → 로그라이크가 아니라 **로그라이트**.

### 구조 초안
- **영구 수집함**: 원정 저장과 별도로 브라우저에 보관(`localStorage` 다른 키). 원정이 끝나면(패배·완수 모두) 도달한 막에 따라 부위를 지급.
- **부위 3종**: 머리(능력치 위주: 체력·공격·마나), 상체(특수 능력), 하체(이동·회피·공속 등).
- **장착 화면**: 새 원정 전에 "준비실"에서 유닛 종류별로 부위를 끼운다. 그 유닛을 상점에서 살 때마다 장착 부위가 적용.
- **그림**: 장착한 부위가 딱지·카드 그림에도 보이게(레이어 초상화).

### 정해야 할 것
1. 부위는 특정 유닛 전용인가, 아무 유닛에나 끼우는가(예: 수염 머리는 전사만?)
2. 장착 한도: 유닛마다 3부위 전부? 한 원정에 총 몇 개까지?
3. 같은 유닛 여러 장(★ 합성용)에 모두 적용되는가?
4. 지급량: 도달 막·처치 수·완수 여부에 따라 몇 개, 희귀도(일반·희귀·전설)?
5. 중복 부위: 강화 재료로 쓸지, 분해해서 재화로 바꿀지
6. 난이도와의 관계: 메타 성장으로 쉬워지는 만큼 어려움·지옥 해금, 또는 높은 난이도에서 더 좋은 부위
7. 첫 판(수집함이 비었을 때) 밸런스가 지금과 같은지

### 부위 예시(초안)
| 부위 | 이름 | 효과 |
|---|---|---|
| 머리 | 수염 달린 머리 | 체력 +10% |
| 머리 | 투구 쓴 머리 | 받는 피해 −5% |
| 머리 | 현자의 두건 | 고유기 마나 −10% |
| 상체 | 돌격 갑옷 | 칸을 움직일 때마다 무작위 적에게 기본 공격 1회(100%) |
| 상체 | 가시 조끼 | 받은 근접 피해 15% 반사 |
| 하체 | 날랜 장화 | 이동 속도 +30%, 첫 3초 회피 +20% |
| 하체 | 무거운 각반 | 밀려나지 않음, 체력 +5% |
