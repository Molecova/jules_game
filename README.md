## Paper Token Forces (페이퍼 토큰 포스, v4) — `v4/index.html` (폰 한 화면)

오토체스식 상점·합성으로 바꾼 버전. 설계는 `docs/v4-design.md`, 화면 시안은 `concepts/v4-phone.html`.

- **유닛 27종**: 전사·궁수·마법사. 25종은 마나 고유기, 광전사·용병은 패시브를 가진다.
- **스킬 칩 64종 · 아이템 38종**: 유닛당 칩 1칸, 칩은 재사용 대기시간 또는 패시브 조건으로 발동. 아이템 6종에는 액티브가 있다.
- **시너지**: 유닛 성격 10종과 무기 스타일 9종. 판 왼쪽 레일을 누르면 효과와 구성원을 볼 수 있다.
- **막별 병력**: 1막 4~5→5~6기, 2막 8~10→10~12기, 3막 3~4기 강적, 4막 5~6→6~7기, 5막 3~4→10~12기. 수가 많은 적은 개체 위력을 낮추며 전반·후반 편성을 다르게 합니다.
- **적 다양화**: 1~5막 일반 적 60종(신규 20종), 기존 10종의 대표 행동 개편. 전용 능력 30개, 일반전 템플릿 30개, 정예 조합 15개와 보스 호위 변형.
- **공격 연출**: 궁수 9종·마법사 9종의 투사체와 명중 효과를 개별화했다. 기본 공격 수치·비행 속도는 유지한다.
- **미리보기**: [달라진 전장](concepts/v4-enemy-encounters.html)에서 5막의 30개 전투와 18종 기본 공격을 재생한다. [구현·검증 기록](docs/enemy-variety-implementation.md).
- **상점 단계 → 전투 단계**: 칸에 들어가면 먼저 상점 단계. 적 3줄과 내 3줄이 모두 보이는 판 아래에 상점(유닛·스킬·아이템 탭, 한 번에 5장)이 있어 적 배치를 보며 바로 사고 배치한다. 전투 시작을 누르면 같은 판에서 싸운다.
- **상점**: 매 라운드 유닛·스킬·아이템이 5장씩. 위 탭으로 종류를 바꾸고(합성 가능한 카드가 있는 탭에 ★2 표시), 탭 옆 1골드 다시 뽑기·잠금은 지금 탭에 적용. 카드 탭 = 정보(다시 탭하면 닫힘), 구매 버튼으로만 구매. 경제 줄에 골드·이자, 레벨·경험치, 레벨업. 등급 확률은 원정대 레벨에 따라 오른다(레벨을 탭하면 표). 카드마다 장수가 정해진 공유 풀.
- **딱지 상세**: 딱지를 탭하면 시너지·유물까지 반영한 능력치(올라간 값은 ▲)와 함께 '스킬'(재사용 대기시간·실제 피해·회복 수치와 범위)과 '무기·아이템'(능력치·고유 효과)을 구역을 나눠 보여 주고 칸을 탭하면 설명이 펼쳐지고, 빼기 버튼으로만 뺀다. 판매·창고로 버튼.
- **드래그 배치**: 창고 딱지를 보드로, 보드 딱지를 다른 칸·창고로 끌어 놓기(겹치면 자리 바꿈). 창고의 스킬·아이템을 딱지 위로 끌어 장착. 탭으로 고르고 빈 칸을 탭해 놓는 방식도 그대로. 딱지를 고른 상태에서 다른 딱지를 탭하면 그 딱지 정보로 바뀐다(자리 바꾸기는 드래그로).
- **카드 디자인**: 유닛은 둥근 종이 카드, 스킬은 육각 무늬에 점선 안쪽 테, 아이템은 리벳 박힌 금속판. 카드 바탕색이 등급(1 흰색 · 2 녹색 · 3 파랑 · 4 보라 · 5 노랑), 유닛·스킬·아이템 카드와 딱지의 테두리는 클래스색(전사 남색 · 궁수 빨강 · 마법사 청록, 공용 회색).
- **보드게임 판**: 나무 테 위에 인쇄된 판. 칸은 둥근 모서리에 위가 밝고 아래가 어두운 홈, 테두리에 좌표(A~E, 1~6)와 '적 진영 / 아군 진영', 가운데는 리본 전선. 딱지 아래 그림자. 막마다 칸 색이 바뀐다(숲·폐허·화산·얼음·심연), 지도 바탕색도 막마다 다르고 막이 바뀌면 막 이름 도장이 찍힌다.
- **전투 기록**: 전투 화면의 기록 버튼 → 딱지별 입힌 피해·받은 피해·회복/보호막과 MVP. 여는 동안 전투 일시 정지, 머리글 탭으로 정렬.
- **창고 8칸 · 합성**: 같은 카드 3장 → ★2, ★2 3장 → ★3(유닛·스킬·아이템 모두). 유닛 ★2는 체력·공격 ×2(스킬 위력 ×1.7), ★3은 ×4(×2.8)로 합성 가치가 크다. 스킬 ★3은 범위가 넓어진다.
- **고유기와 칩**: 유닛 고유기는 공격·피격으로 마나를 모아 사용하고, 스킬 칩과 아이템 액티브는 각자의 재사용 대기시간마다 발동합니다. 스킬 칩은 유닛당 1개입니다. 창고가 꽉 차도 합성되는 구매는 가능합니다.
- **경제**: 보통은 시작 6골드, 첫 노드 이후 수입 5 + 이자(최대 5), 일반전 승리 +1. 경험치 노드마다 +2, 4골드로 +4. 레벨 = 출전 인원(3→9).
- **원정**: 5막 × (8층 + 보스) = 45라운드 — 어둠의 숲, 망자의 폐허, 용의 화산, 얼어붙은 봉우리, 심연의 성채. 전투·정예·암시장·대장간(복제·개조)·야영지·이벤트(12종)·보물. 보스는 막마다 2종 중 무작위(4막 얼음 여왕 시엘라·설인 왕 우가, 5막 심연의 군주 녹스·타락한 왕 모르간).
- **패배 = 원정 끝**(로그라이크). 난이도 3단계: 보통, 어려움, 지옥. 어려움은 시작 8골드·노드 기본 수입 6·경험치 3, 지옥은 시작 14골드·기본 수입 8·경험치 4로 강한 적에 대비합니다. 불사조 깃털 유물이 있으면 패배 1회를 넘깁니다. 유물 31종.
- **밸런스**: 난이도 배수는 적 체력·공격력(스킬 위력 포함) 모두 보통 1.0 · 어려움 1.5 · 지옥 2.0입니다. 실제 원정으로 막별 병력·성장·보스를 조정한 뒤, 유닛·스킬·무기 129종의 1·2·3성과 장착 조합을 추가 검증했습니다. [카드 패치 전후 비교·결과](docs/card-balance-2026-10-07.md), [이전 적·진행 패치](docs/balance-2026-10-07.md), [전체 카드 성급표](docs/balance-list.md). 자동 플레이 완주율은 사람의 승률을 뜻하지 않으며 지옥의 완수 가능성은 아직 검증하지 못했습니다.
- **편의**: 경제 줄의 레벨을 탭하면 레벨별 상점 등급 확률표. 타이틀에 원정 수·최고 도달·난이도별 완수 기록.

```
shared/engine.js      공용 엔진: 사각/헥스 그리드, BFS 이동, 자동 전투(공격·마나·스킬·투사체), 로스터/합성, 입력·렌더 유틸
shared/shopgame.js    상점형 흐름(A·B·C): 준비→전투→결과, 골드/이자/연승, 경험치/레벨, 상점, 적 편성
concepts/*.html       시안별 유닛 데이터, 시너지, 고유 규칙(hooks), 화면
```

## 실행

- 파일을 브라우저로 열기: `index.html`
- 또는 로컬 서버: `npx serve .`

## 스킬 이펙트 시안

`concepts/v4-skill-effects.html`에서 현재 고유기 25개·스킬 칩 64개·아이템 액티브 6개, 무기 기본 공격 38개와 패시브 연출을 선택해 재생합니다. ★1~★3, 일시정지·타임라인, 연출·지속 상태 표시를 조작할 수 있습니다. 같은 `v4/vfx4.js`와 `v4/projectiles4.js`를 실제 전투에서도 사용합니다. [전체 id별 변경·검증 기록](docs/vfx-implementation-2026-10-06.md)을 참고하세요.

- 단일 HTML로 내보내기: `python3 scripts/build-skill-preview.py /tmp/card-expedition-preview` → `skill-effects.html`, `game-with-effects.html`, `enemy-encounters.html`
- 전투 결과·난수·이펙트 이벤트 회귀 검사: `node --test tests/vfx4.test.cjs`
- 이펙트 시안은 외부 파일 요청 없이 실행되는 단일 HTML로도 내보낼 수 있습니다. 게임 내보내기는 Google Fonts가 없어도 시스템 글꼴로 동작합니다.

## v4 버그 회귀 검사

정적 서버(`python3 -m http.server 8000`)와 Node.js, Playwright, `/usr/bin/chromium`이 필요합니다.

```sh
node --test tests/*.test.cjs
node tests/browser-smoke.cjs
node tests/browser-enemies.cjs
node tests/browser-bugfixes.cjs
node tests/browser-scenes.cjs
node tests/browser-run.cjs
node tests/browser-vfx.cjs
node tests/browser-new-weapons.cjs
```

저장 데이터 검증·백업은 `v4/save4.js`, 전투 전용 RNG는 `AC.rng`와 전투별 `BT4.create({ random })`에 있습니다. 대장간은 별에 해당하는 실제 사본 수로 풀을 정산하며, 재료/결과 카드가 부족하면 비용을 지불하거나 재료를 소모하지 않습니다. 다음 전투 체력 페널티가 겹치면 더 낮은 시작 체력을 유지합니다.
