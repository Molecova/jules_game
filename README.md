# 오토체스 탑뷰 2D 시안

## 카드 원정대 v4 — `v4/index.html` (폰 한 화면)

오토체스식 상점·합성으로 바꾼 버전. 설계는 `docs/v4-design.md`, 화면 시안은 `concepts/v4-phone.html`.

- **3클래스**: 전사·궁수·마법사, 유닛 27종(클래스마다 1~4등급 2종씩 + 5등급 1종). 스킬 칩 45종과 아이템 27종은 클래스 전용(공용 스킬 5종만 예외).
- **역할은 아이템이 정한다**: 쌍단검을 끼운 전사는 적 뒤로 도약하는 도적, 성스러운 철퇴면 아군을 치유하는 성기사, 성서를 든 마법사는 힐러가 된다.
- **특성 시너지 11종**: 딱지마다 클래스 1개 + 특성 2개(불꽃: 광전사·화염술사·흑마법사). 기본 시너지(정해진 수만큼 모이면)와 특별 조합(지정 유닛 전원이 모이면).
- **시너지 레일**: 판 왼쪽 나무 테의 홈에 시너지 패가 세로로 박혀 있다(아이콘 · 이름 · 단계 눈금 · 현재/다음). 켜진 것이 위에서 빛나고, 탭하면 설명, 맨 아래 '전체'로 전체 목록. 상점·전투 모두 보인다. 화면이 넉넉하면 상점 카드에 설명 두 줄이 붙는다.
  - 기사(견습 검사·기사단장·용기사, 2/3): 받는 피해 −15%/−30%
  - 견습(견습 검사·견습 궁수·견습 마법사 전원): 모든 아군 피해 +15%, 스킬 마나 −15%, 받는 피해 −15%
  - 수호자(방패병·기사단장·약초꾼·학자, 2/4): 시작 보호막 150/400
  - 용병단(용병·결투가·석궁병, 2/3): 승리 골드 +1/+2, 공속 +20%
  - 명사수(정찰병·석궁병·레인저·엘프 명궁, 2/3/4): 치명타·치명 피해·사거리
  - 야생(견습 궁수·정찰병·매사냥꾼·약초꾼, 2/4): 모든 아군 재생 1%/2%, 소환물 강화
  - 비전(학자·점성술사·대마법사·현자, 2/4): 시작 마나 +25, 마나 획득 +30%
  - 별의 인도(점성술사·엘프 명궁·현자 전원): 모든 아군 치명타 +20%, 치명 피해 +50%
  - 스승과 제자(대마법사·견습 마법사 둘 다): 견습 마법사 스킬 위력 ×2, 대마법사 스킬 마나 −30%
  - 베테랑(방패병·용병·결투가·매사냥꾼·레인저·용기사, 2/4/6): 공격력 +15/30/50%, 처치 시 회복
  - 시너지 줄은 작은 칩(글자 + 현재/다음 단계, 켜지면 색이 참)으로 켜진 것부터 한 줄에. '시너지 전체' 버튼으로 전체 목록(보유·출전 표시). 도감에도 시너지 탭.
  - 상점 유닛 카드는 클래스색 띠(전사 남색·궁수 빨강·마법사 청록)로 두르고, 카드 안에 특성 이름 두 개를 적는다.
- **상점 단계 → 전투 단계**: 칸에 들어가면 먼저 상점 단계. 적 3줄과 내 3줄이 모두 보이는 판 아래에 상점(유닛·스킬·아이템 탭, 한 번에 5장)이 있어 적 배치를 보며 바로 사고 배치한다. 전투 시작을 누르면 같은 판에서 싸운다.
- **상점**: 매 라운드 유닛·스킬·아이템이 5장씩. 위 탭으로 종류를 바꾸고(합성 가능한 카드가 있는 탭에 ★2 표시), 탭 옆 1골드 다시 뽑기·잠금은 지금 탭에 적용. 카드 탭 = 정보(다시 탭하면 닫힘), 구매 버튼으로만 구매. 경제 줄에 골드·이자, 레벨·경험치, 레벨업. 등급 확률은 원정대 레벨에 따라 오른다(레벨을 탭하면 표). 카드마다 장수가 정해진 공유 풀.
- **딱지 상세**: 딱지를 탭하면 시너지·유물까지 반영한 능력치(올라간 값은 ▲)와 함께 '스킬'(칩마다 마나·실제 피해·회복 수치와 범위)과 '무기·아이템'(능력치·고유 효과)을 구역을 나눠 보여 주고 칸을 탭하면 설명이 펼쳐지고, 빼기 버튼으로만 뺀다. 판매·창고로 버튼.
- **드래그 배치**: 창고 딱지를 보드로, 보드 딱지를 다른 칸·창고로 끌어 놓기(겹치면 자리 바꿈). 창고의 스킬·아이템을 딱지 위로 끌어 장착. 탭으로 고르고 빈 칸을 탭해 놓는 방식도 그대로. 딱지를 고른 상태에서 다른 딱지를 탭하면 그 딱지 정보로 바뀐다(자리 바꾸기는 드래그로).
- **카드 디자인**: 유닛은 둥근 종이 카드, 스킬은 육각 무늬에 점선 안쪽 테, 아이템은 리벳 박힌 금속판. 카드 바탕색이 등급(1 흰색 · 2 녹색 · 3 파랑 · 4 보라 · 5 노랑), 유닛·스킬·아이템 카드와 딱지의 테두리는 클래스색(전사 남색 · 궁수 빨강 · 마법사 청록, 공용 회색).
- **보드게임 판**: 나무 테 위에 인쇄된 판. 칸은 둥근 모서리에 위가 밝고 아래가 어두운 홈, 테두리에 좌표(A~E, 1~6)와 '적 진영 / 아군 진영', 가운데는 리본 전선. 딱지 아래 그림자. 막마다 칸 색이 바뀐다(숲·폐허·화산·얼음·심연), 지도 바탕색도 막마다 다르고 막이 바뀌면 막 이름 도장이 찍힌다.
- **전투 기록**: 전투 화면의 기록 버튼 → 딱지별 입힌 피해·받은 피해·회복/보호막과 MVP. 여는 동안 전투 일시 정지, 머리글 탭으로 정렬.
- **창고 8칸 · 합성**: 같은 카드 3장 → ★2, ★2 3장 → ★3(유닛·스킬·아이템 모두). 유닛 ★2는 체력·공격 ×2(스킬 위력 ×1.7), ★3은 ×4(×2.8)로 합성 가치가 크다. 스킬 ★3은 범위가 넓어진다.
- **스킬마다 마나**: 딱지에 꽂은 스킬 칩은 각자 마나 막대가 따로 차고, 찬 칩부터 시전. 판 위 딱지 아래에 칩 수만큼 마나 줄, 전투 아래 줄에는 칩마다 마나 점. 창고가 꽉 차도 합성되는 구매는 가능.
- **경제**: 라운드 수입 5 + 이자(최대 5) + 연승 보너스, 승리 +1. 경험치 라운드마다 +2, 4골드로 +4. 레벨 = 출전 인원(3→9).
- **원정**: 5막 × (5층 + 보스) = 30라운드 — 어둠의 숲, 망자의 폐허, 용의 화산, 얼어붙은 봉우리, 심연의 성채. 전투·정예·암시장·대장간(복제·개조)·야영지·이벤트(13종)·보물. 보스는 막마다 2종 중 무작위(4막 얼음 여왕 시엘라·설인 왕 우가, 5막 심연의 군주 녹스·타락한 왕 모르간).
- **패배 = 원정 끝**(로그라이크). 난이도 3단계: 쉬움(적이 약하고 불사조 깃털로 패배 1회 무효), 보통, 어려움(적이 강하고 수입 −1). 유물 31종.
- **밸런스**: 자동 봇 수백 판 기준 5막 완주율 쉬움 약 60% · 보통 약 30% · 어려움 약 10%(적 강도 계수 1.09 · 1.22 · 1.34). 일반 전투는 거의 지지 않고 정예·보스가 고비이며, 뒤 막일수록 어렵다. 아이템·유물·스킬의 기본 성능은 낮추고 별(★) 합성이 강해지는 쪽으로.
- **편의**: 경제 줄의 레벨을 탭하면 레벨별 상점 등급 확률표. 타이틀에 원정 수·최고 도달·난이도별 완수 기록.

## 카드 원정대 (D안 발전판 v3) — `game/index.html`

종이 딱지와 플라스틱 말로 하는 보드게임 느낌의 오토배틀 로그라이크. 약 20~30분.

- **딱지 위에 올리는 장비**: 유닛은 그림이 인쇄된 둥근 종이 딱지. 스킬은 육각 플라스틱 칩(유닛당 최대 2개), 무기는 미니어처(유닛당 1개)로 딱지 위 슬롯에 실제로 꽂혀 보이고, 레벨은 금색 핀으로 표시. 쓰러지면 딱지가 반으로 찢어짐.
- **편성 화면**: 지도에서 언제든 열어 칩·무기를 끼우고 빼기. 같은 계열(공용 칩은 누구나)만 장착.
- **유닛 31종 · 6계열**: 검·수호·궁·마법·신성·암살. 유닛마다 고유 패시브, 계열 2/4명 시너지, 전투 경험치로 레벨업(최대 5).
- **스킬 칩 52종**: 앞 2칸+옆 1칸 같은 격자 패턴, 직선·연쇄·도약·일제사격 등. 화상·중독·출혈·둔화·약화·취약·기절·재생·가속·강건·패리 상태이상.
- **무기 31종**: 스탯 보정과 적중 효과(출혈, 연쇄 번개, 흡혈 등).
- **전술 카드 21종**: 전투마다 덱에서 뽑아 에너지로 즉시 사용(치유, 돌격 명령, 화염병 등).
- **원정**: 3막 갈림길 지도(전투·정예·이벤트·상점·대장간·야영지·보물), 막마다 보스가 무작위(고블린 왕/슬라임 왕/리치/흡혈귀 백작), 최종 보스 흑룡. 유물 30종, 이벤트 12종.
- **시작 분대 3종 · 난이도 3단계**.
- **도감**: 유닛·스킬 칩·무기·전술·몬스터·보스·유물·상태이상을 모두 열람(만난 것은 표시).
- **저장**: 지도 화면마다 자동 저장, 타이틀에서 이어하기.
- **연출·사운드**: 투사체, 도장 스타일 피해 숫자, 종이 파편, 보스 예고 칸, 합성 효과음(HUD에서 끄기).

## 처음 시안 4종

시안 보드(`index.html`)에는 D안만 남겼습니다. A·B·C 파일은 참고용으로 `concepts/`에 그대로 두었습니다.

브라우저에서 바로 실행되는 오토체스(오토배틀러) 프로토타입 4종입니다. 빌드 과정 없이 `index.html`을 열면 됩니다.

| 시안 | 파일 | 핵심 |
| --- | --- | --- |
| A 헥스 왕국 | `concepts/a-hex.html` | 헥스 7×8, 상점·레벨·3합성, 직업+출신 시너지 (TFT 계열 표준안) |
| B 픽셀 체스 | `concepts/b-pixel.html` | 8×8 체스판, 30초 준비 타이머, 크립 라운드, 암살자 잠입·언데드 부활 (도타 오토체스 계열) |
| C 네온 서킷 | `concepts/c-neon.html` | 7×8 4방향 이동, 라운드마다 바뀌는 지형(벽·엄폐·오버클럭), 아이템 칩 장착 |
| D 카드 원정대 | `concepts/d-deck.html` | 상점 대신 덱빌딩, 에너지로 유닛·주문 카드 사용, 10전투 로그라이크 원정 |

## 구조

```
index.html            시안 목록과 비교표
shared/engine.js      공용 엔진: 사각/헥스 그리드, BFS 이동, 자동 전투(공격·마나·스킬·투사체), 로스터/합성, 입력·렌더 유틸
shared/shopgame.js    상점형 흐름(A·B·C): 준비→전투→결과, 골드/이자/연승, 경험치/레벨, 상점, 적 편성
concepts/*.html       시안별 유닛 데이터, 시너지, 고유 규칙(hooks), 화면
```
