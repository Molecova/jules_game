# 오토체스 탑뷰 2D 시안

## 카드 원정대 v4 — `v4/index.html` (폰 한 화면)

오토체스식 상점·합성으로 바꾼 버전. 설계는 `docs/v4-design.md`, 화면 시안은 `concepts/v4-phone.html`.

- **3클래스**: 전사·궁수·마법사, 유닛 18종(1~5등급). 스킬 칩 30종과 아이템 18종은 클래스 전용(공용 스킬 3종만 예외).
- **역할은 아이템이 정한다**: 쌍단검을 끼운 전사는 적 뒤로 도약하는 도적, 성스러운 철퇴면 아군을 치유하는 성기사, 성서를 든 마법사는 힐러가 된다.
- **상점**: 매 라운드 유닛·스킬·아이템이 5장씩. 카드 탭 = 정보(다시 탭하면 닫힘), 구매 버튼으로만 구매. 골드는 상점 줄 왼쪽(탭하면 다음 수입 계산), 다음 이자는 창고 이름 옆. 줄마다 1골드 다시 뽑기·잠금. 등급 확률은 원정대 레벨에 따라 오른다. 카드마다 장수가 정해진 공유 풀.
- **딱지 상세**: 딱지를 탭하면 시너지·유물까지 반영한 능력치(올라간 값은 ▲), 장착 스킬의 실제 피해·회복 수치와 범위, 아이템 효과를 한 판에 보여 주고 칸을 탭하면 설명이 펼쳐지고, 빼기 버튼으로만 뺀다. 판매·창고로 버튼.
- **드래그 배치**: 창고 딱지를 보드로, 보드 딱지를 다른 칸·창고로 끌어 놓기(겹치면 자리 바꿈). 창고의 스킬·아이템을 딱지 위로 끌어 장착. 탭으로 고르고 빈 칸을 탭해 놓는 방식도 그대로. 딱지를 고른 상태에서 다른 딱지를 탭하면 그 딱지 정보로 바뀐다(자리 바꾸기는 드래그로).
- **전투 기록**: 전투 화면의 기록 버튼 → 딱지별 입힌 피해·받은 피해·회복/보호막과 MVP. 여는 동안 전투 일시 정지, 머리글 탭으로 정렬.
- **창고 8칸 · 합성**: 같은 카드 3장 → ★2, ★2 3장 → ★3(유닛·스킬·아이템 모두). 스킬 ★3은 범위가 넓어진다. 창고가 꽉 차도 합성되는 구매는 가능.
- **경제**: 라운드 수입 5 + 이자(최대 5) + 연승 보너스, 승리 +1. 경험치 라운드마다 +2, 4골드로 +4. 레벨 = 출전 인원(3→8).
- **원정**: 3막 × (5층 + 보스) = 18라운드. 전투·정예·암시장·대장간(복제·개조)·야영지·이벤트·보물. 보스는 막마다 무작위, 최종 흑룡.
- **패배 = 원정 끝**(로그라이크). 쉬움은 적이 약하고 불사조 깃털(패배 1회 무효)을 들고 시작. 유물 21종.
- **밸런스**: 자동 플레이 봇 40판 기준 보통 클리어 약 50~60%, 쉬움 약 95%.

| `v4/battle4.js` | 별·아이템 효과·시너지·유물을 반영한 전투 개체, 스킬 실행, 보스 패턴 |

몬스터·막 데이터(`game/data.js`), 딱지 아트(`game/art.js`), 효과음(`game/sfx.js`), 전투 엔진(`shared/engine.js`)은 v3와 함께 쓴다.

## 카드 원정대 (D안 발전판 v3) — `game/index.html`

종이 딱지와 플라스틱 말로 하는 보드게임 느낌의 오토배틀 로그라이크. 약 20~30분.

- **딱지 위에 올리는 장비**: 유닛은 그림이 인쇄된 둥근 종이 딱지. 스킬은 육각 플라스틱 칩(유닛당 최대 2개), 무기는 미니어처(유닛당 1개)로 딱지 위 슬롯에 실제로 꽂혀 보이고, 레벨은 금색 핀으로 표시. 쓰러지면 딱지가 반으로 찢어짐.
- **편성 화면**: 지도에서 언제든 열어 칩·무기를 끼우고 빼기. 같은 계열(공용 칩은 누구나)만 장착.
- **유닛 31종 · 6계열**: 검·수호·궁·마법·신성·암살. 유닛마다 고유 패시브, 계열 2/4명 시너지, 전투 경험치로 레벨업(최대 5).
- **스킬 칩 52종**: 앞 2칸+옆 1칸 같은 격자 패턴, 직선·연쇄·도약·일제사격 등. 화상·중독·출혈·둔화·약화·취약·기절·재생·가속·강건·패리 상태이상.
- **무기 31종**: 스탯 보정과 적중 효과(출혈, 연쇄 번개, 흡혈 등).
- **전술 카드 21종**: 전투마다 덱에서 뽑아 에너지로 즉시 사용(치유, 돌격 명령, 화염병 등).
- **원정**: 3막 갈림길 지도(전투·정예·이벤트·상점·대장간·야영지·보물), 막마다 보스가 무작위(고블린 왕/슬라임 왕/리치/흡혈귀 백작), 최종 보스 흑룡. 유물 30종, 이벤트 12종.
- **시작 분대 3종 · 난이도 3단계**.
- **도감**: 유닛·스킬 칩·무기·전술·몬스터·보스·유물·상태이상을 모두 열람(만난 것은 표시).
- **저장**: 지도 화면마다 자동 저장, 타이틀에서 이어하기.
- **연출·사운드**: 투사체, 도장 스타일 피해 숫자, 종이 파편, 보스 예고 칸, 합성 효과음(HUD에서 끄기).

## 처음 시안 4종

시안 보드(`index.html`)에는 D안만 남겼습니다. A·B·C 파일은 참고용으로 `concepts/`에 그대로 두었습니다.

브라우저에서 바로 실행되는 오토체스(오토배틀러) 프로토타입 4종입니다. 빌드 과정 없이 `index.html`을 열면 됩니다.

| 시안 | 파일 | 핵심 |
| --- | --- | --- |
| A 헥스 왕국 | `concepts/a-hex.html` | 헥스 7×8, 상점·레벨·3합성, 직업+출신 시너지 (TFT 계열 표준안) |
| B 픽셀 체스 | `concepts/b-pixel.html` | 8×8 체스판, 30초 준비 타이머, 크립 라운드, 암살자 잠입·언데드 부활 (도타 오토체스 계열) |
| C 네온 서킷 | `concepts/c-neon.html` | 7×8 4방향 이동, 라운드마다 바뀌는 지형(벽·엄폐·오버클럭), 아이템 칩 장착 |
| D 카드 원정대 | `concepts/d-deck.html` | 상점 대신 덱빌딩, 에너지로 유닛·주문 카드 사용, 10전투 로그라이크 원정 |

## 구조

```
index.html            시안 목록과 비교표
shared/engine.js      공용 엔진: 사각/헥스 그리드, BFS 이동, 자동 전투(공격·마나·스킬·투사체), 로스터/합성, 입력·렌더 유틸
shared/shopgame.js    상점형 흐름(A·B·C): 준비→전투→결과, 골드/이자/연승, 경험치/레벨, 상점, 적 편성
concepts/*.html       시안별 유닛 데이터, 시너지, 고유 규칙(hooks), 화면
```

## 실행

- 파일을 브라우저로 열기: `index.html`
- 또는 로컬 서버: `npx serve .`

- 단축키(A·B·C): `D` 새로고침, `F` 경험치 구매, `E` 선택 유닛 판매, `Space` 전투 시작
