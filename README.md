# 오토체스 탑뷰 2D 시안

## 카드 원정대 (D안 발전판) — `game/index.html`

약 20분 분량의 덱빌딩 오토배틀 로그라이크.

- **원정 구조**: 3막(어둠의 숲 → 망자의 폐허 → 용의 화산). 막마다 7층 지도에 갈림길이 생성되고, 전투·정예·이벤트·상점·야영지·보물 노드를 골라 올라갑니다. 막의 끝은 보스(고블린 왕 → 리치 → 최종 보스 흑룡 아자르).
- **카드**: 유닛 카드(검·궁·마법·신성 계열)와 스킬 카드. 스킬 카드는 같은 계열 유닛(공용 스킬은 아무 유닛)에게 붙이며, 유닛은 마나가 찰 때마다 붙은 스킬을 순서대로 씁니다.
- **격자 패턴 스킬**: 예) 십자 베기 = 앞 2칸 + 앞칸 양옆, 회전 베기 = 주변 8칸, 돌진 찌르기 = 앞 3칸, 화염 폭발 = 대상 중심 십자, 메테오 = 1.2초 뒤 3×3. 카드에 5×5 범위 그림이 있고, 스킬 카드를 든 채 유닛 위에 올리면 보드에 범위가 미리 표시됩니다.
- **보스 패턴**: 빨간 예고 칸이 차오른 뒤 피해(내려찍기, 저주, 화염 브레스, 꼬리 휩쓸기, 운석). 소환, 2페이즈 분노.
- **성장**: 전투 보상 카드, 상점 구매/카드 제거, 야영지 강화(유닛 ★, 스킬 +), 유물 14종.
- **저장**: 지도 화면마다 브라우저에 자동 저장, 타이틀에서 이어하기.

| 파일 | 내용 |
| --- | --- |
| `game/data.js` | 카드·스킬 패턴·몬스터·막·유물·이벤트 데이터 |
| `game/game.js` | 지도 생성, 전투 준비/배치, 스킬 실행, 보스 패턴, 보상·상점·야영지·이벤트, 저장 |
| `shared/engine.js` | 공용 자동 전투 엔진 (도발·고정형 보스·틱 훅·소환 지원 추가) |

## 처음 시안 4종

브라우저에서 바로 실행되는 오토체스(오토배틀러) 프로토타입 4종입니다. 빌드 과정 없이 `index.html`을 열면 됩니다.

| 시안 | 파일 | 핵심 |
| --- | --- | --- |
| A 헥스 왕국 | `concepts/a-hex.html` | 헥스 7×8, 상점·레벨·3합성, 직업+출신 시너지 (TFT 계열 표준안) |
| B 픽셀 체스 | `concepts/b-pixel.html` | 8×8 체스판, 30초 준비 타이머, 크립 라운드, 암살자 잠입·언데드 부활 (도타 오토체스 계열) |
| C 네온 서킷 | `concepts/c-neon.html` | 7×8 4방향 이동, 라운드마다 바뀌는 지형(벽·엄폐·오버클럭), 아이템 칩 장착 |
| D 카드 원정대 | `concepts/d-deck.html` | 상점 대신 덱빌딩, 에너지로 유닛·주문 카드 사용, 10전투 로그라이크 원정 |

## 구조

```
index.html            시안 목록과 비교표
shared/engine.js      공용 엔진: 사각/헥스 그리드, BFS 이동, 자동 전투(공격·마나·스킬·투사체), 로스터/합성, 입력·렌더 유틸
shared/shopgame.js    상점형 흐름(A·B·C): 준비→전투→결과, 골드/이자/연승, 경험치/레벨, 상점, 적 편성
concepts/*.html       시안별 유닛 데이터, 시너지, 고유 규칙(hooks), 화면
```

## 실행

- 파일을 브라우저로 열기: `index.html`
- 또는 로컬 서버: `npx serve .`

## 조작

- 유닛 드래그 또는 탭 → 칸 탭으로 배치, 상점 위로 끌어다 놓으면 판매
- 단축키(A·B·C): `D` 새로고침, `F` 경험치 구매, `E` 선택 유닛 판매, `Space` 전투 시작
