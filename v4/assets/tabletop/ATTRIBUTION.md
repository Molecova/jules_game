# Tabletop PBR textures

The following ambientCG materials are **CC0 1.0**:

- [Wood062](https://ambientcg.com/a/Wood062), multi-angle photographed wood.
- [Rock030](https://ambientcg.com/a/Rock030), see `manifest.json` for the source's creation method.
- [ambientCG licensing](https://docs.ambientcg.com/license/)
- [CC0 1.0 legal text](https://creativecommons.org/publicdomain/zero/1.0/)

The source was ambientCG's own material-shading preview maps, linked by its official API. The ZIP download endpoint was unavailable in this environment. The actual publicly hosted color, DirectX normal, and roughness maps were downloaded through their official preview links instead.

Color maps were resized from 2048 to 1024 pixels. Normal and roughness maps were resized to 512 pixels. JPEG quality is 90 (normal 94), using Lanczos resizing. `manifest.json` records the original URLs and SHA-256 hashes, transformations, and derived-file hashes. The runtime flips the DirectX normal Y component via `normalScale.y < 0`.

The game serves these files locally, with no runtime CDN. Normal quality samples color at 768 pixels and normal/roughness at 512; low quality uses 512/256. Board-tile albedo blends the procedural Rock030 color map with a light neutral surface to retain the original game's readability. Felt and scenery models are generated by project code.
