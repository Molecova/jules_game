카드 원정대 v4 · UI 개선 시안

상점과 전투 화면, 이렇게 바꿔 보면 어떨까요

지금 화면에서 걸리는 점을 먼저 짚고, 상점 시안 3개와 전투 시안 2개를 실제 딱지·칩 그림으로 그렸습니다. 모두 390×844 폰 화면 한 장에 들어가는 크기입니다.

지금 화면에서 걸리는 점

  1. 시너지 태그가 유닛 그림을 덮어 누구인지 안 보임. 유닛 줄만 높이면 균형이 깨짐.
  2. 오른쪽 줄마다 붙은 유닛/↻/잠금 기둥이 폭의 15%를 먹고 표처럼 보임.
  3. 동전·"1장"·클래스 원이 카드 모서리에 몰리고, 동전이 윗줄 카드에 걸침.
  4. 골드·이자·적 필드·레벨업·경험치가 네 군데로 흩어짐. 경험치는 맨 위, 레벨업 버튼은 맨 아래.
  5. 모든 요소에 굵은 테두리와 그림자 → 무엇이 중요한지(전투 시작) 덜 보임.
  6. 이름이 잘림(견습 마…, 견습 지…).
  1. 판 위아래로 큰 빈 공간. 적 목록은 위에 작게, 아군 목록은 아래 두 줄로 나뉨.
  2. 전투 중엔 쓸 일이 없는 시너지 줄이 그대로 자리를 차지.
  3. 누가 이기고 있는지, 몇 초째인지 한눈에 안 보임(위쪽엔 레벨·경험치가 남아 있음).
  4. 배속·결과 바로 보기·기록 버튼이 같은 무게라 주 조작이 흐림.
  5. 아군 이름이 잘리고(견습…), 피해 숫자가 겹쳐 MISS MISS처럼 보임.

상점 시안

A

정돈형
  • 경제 한 줄: 골드·이자 | 레벨·경험치·레벨업 | 적 필드를 한 막대에.
  • 줄 머리표: 기둥 대신 각 줄 위에 얇은 "유닛 ─ ↻1 · 잠금". 카드가 폭을 다 씀.
  • 유닛 카드는 위쪽 클래스 띠 + 그림 + 이름 + 시너지 두 줄 글씨. 그림을 덮지 않음.
  • 켜진 시너지는 이름까지, 나머지는 글자 칩. 맨 아래 전투 시작 하나만 크게.
B

큰 카드 서랍형
  • 상점은 한 종류씩 크게(유닛/스킬/아이템 탭, ★2 가능하면 탭에 표시).
  • 카드에 설명 한 줄까지 들어가 정보창을 덜 열어도 됨.
  • 판·창고가 넉넉해지고 화면이 가장 차분함.
  • 대신 세 줄을 한눈에 보던 장점은 줄어듦(탭 전환 필요).
C

시너지 레일형
  • 시너지를 판 왼쪽 세로 레일로(롤토체스처럼). 이름·단계가 늘 보이고 줄 하나가 사라짐.
  • 상점 세 줄은 그대로, 다시 뽑기는 줄 끝 동그란 버튼으로.
  • 레벨·경험치는 레벨업 버튼 안에.
  • 판이 조금 좁아짐(내 진영 세 줄이라 충분).

전투 시안

A

스코어보드형
  • 맨 위 줄다리기 막대: 아군 전체 체력 vs 적 전체 체력, 가운데 시간.
  • 판을 최대 크기로, 시너지 줄과 적 목록은 뺌(적은 판에서 보임).
  • 아래 딱지 한 줄: 체력 고리 + 마나 점, 쓰러지면 흐려짐.
  • 배속은 ×1·×2·×3 버튼 묶음, 건너뛰기·기록은 작게.
B

실시간 딜 미터형
  • 아래에 실시간 피해 순위(입힌 피해 막대 + 받은 피해·회복 숫자, MVP 왕관).
  • 보스전이면 위에 보스 체력 막대와 패턴 이름.
  • 지금의 "기록" 창을 열 필요가 없어짐.
  • 판은 A보다 조금 작음.
추천

상점 A + 전투 A, 여기에 C의 시너지 레일은 선택

A는 지금 구조(내 진영 + 상점 세 줄)를 유지하면서 흩어진 정보만 모아 완성도가 가장 빨리 올라갑니다. 시너지가 더 중요해지면 C의 레일을 얹고, 전투는 A의 줄다리기 막대로 승부가 한눈에 보이게 하는 조합을 제안합니다. 마음에 드는 시안(섞어도 됨)을 골라 주시면 그대로 게임에 옮기겠습니다.
